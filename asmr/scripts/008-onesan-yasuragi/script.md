# ASMR台本：お疲れさま。お姉さんに全部預けて？

## 1. 導入 (おかえりなさい)
「おかえりなさい。ふふ、今日も一日、本当にお疲れさま。……ん？ どうしたの、そんなにぼーっとして。あ、もしかして……今日はいつもより、もっと頑張っちゃった感じかな？」

## 2. 甘やかし (抱擁・よしよし)
「よしよし。顔を見ればわかるよ。君は真面目だから、ついつい無理しちゃうんだもんね。ほら、こっちにおいで？ 荷物置いて、肩の力抜いて……。ぎゅー……。ん、いい子いい子。お姉さんの腕の中は、あったかいでしょう？」

## 3. 核心 (肯定と囁き)
「（耳元で囁くように）……ねぇ、知ってる？ 君が一生懸命なところ、お姉さんはちゃんと見てるよ。世界中の人が気づかなくても、私だけは、君がどれだけ頑張ったか知ってるから。だからね……私の前では、かっこつけなくていいんだよ？」

## 4. 結び (おやすみなさい)
「今日はもう、お姉さんにたっぷり甘やかされて？ 膝枕してあげようか。ふふ、顔赤くなってる。可愛いね。……おやすみなさい、私の大切な頑張り屋さん」
