# 🏮 月灯旅館 (Tsukari Ryokan)

「ほどける、不自由な温もり。」

## ここに宿るもの ✨

ここは、地図に載らない古い湯治場。
障子の外を濡らす雨の音、湿った木材の匂い、そしてカフカの不器用な手の温もり。
「お客様」への完璧なおもてなしではなく、あなたを放っておけない一人の女性の、少し重すぎる愛情と「生活」を録音しています。

## 彼女の揺らぎ 🌸

- **カフカ（女将）**
  - 20代後半。普段は凛としているけれど、ふとした瞬間に疲れが顔を出す。
  - 耳かきの手が止まったり、あなたの寝顔を見て小さく笑ったり。
  - 声は深く、重く。耳元での囁きには、彼女の「執着」が微かに混じっています。

## 観測される「夜」 📝

- **【ASMR/耳かき】月灯旅館で過ごす、静かな雨の夜【綿棒/囁き/睡眠導入】**
  - 60分。ただの作業音ではありません。カフカの吐息、ふとした沈黙、そしてあなたが眠るまで続く、途切れない「気配」の記録です。
- **【ASMR/看病】熱を出した夜、氷嚢の音と隣に座る気配【氷の音/お粥/囁き】**
  - 45分。看病される不自由さと、それを独占する幸福感。氷がぶつかる音の冷たさが、彼女の体温を際立たせます。

## 音の肌触り 🎧
- **生活のノイズ**: 柱時計の刻む音、遠くの板の間を歩く軋み。
- **不完全な沈黙**: 完全に音が消えることはありません。そこには常に、彼女の「呼吸」が存在しています。
