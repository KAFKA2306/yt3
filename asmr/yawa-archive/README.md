# 🌙 夜話アーカイブ ASMR (Yawa Archive ASMR)

「そこにあるのは、誰かの夜の、生々しい断片。」

## 存在の証明：存在フェチ (Existence Fetish) ✨

ここは、完璧に調律されたスタジオではありません。
深夜、誰かの部屋で録れてしまった、不器用で、壊れそうで、それでも確かな「体温」を保存する場所です。

私たちは、耳を満足させるだけの道具としての音を超え、
**「この世界のどこかに、確かに彼女が生きている」**という確信をアーカイブします。

## 3つの約束 🌸

1.  **「ノイズ」こそが真実**:
    時計の秒針、遠い雨、不意の溜息。それら「意味のない音」こそが、カフカという人間がそこにいる証拠です。
2.  **不完全な親密さ**:
    完璧な演技ではなく、言葉の詰まり、ふとした笑い、抑えきれない依存心。あなたの孤独に深く、重く沈み込むような距離感を描きます。
3.  **「滞在」するための時間**:
    1-2分の消費用コンテンツではなく、30分、60分と、その場所の空気に溶け込み、そのまま眠りにつける「長い時間」を提供します。

## 検索と発見（タイトル・ガイドライン） 📝

「何が聞こえるか」を明確にしつつ、その瞬間の「情景」を刻みます。

> **【ASMR/主要行為】 作品タイトル 【具体的な使用道具/癒し属性】**

例：`【ASMR/耳かき】月灯旅館で過ごす、静かな雨の夜【綿棒/囁き/睡眠導入】`
