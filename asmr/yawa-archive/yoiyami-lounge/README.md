# 🍷 宵闇ラウンジ (Yoiyami Lounge)

「繋ぎっぱなしの、心地よい絶望。」

## ここに宿るもの ✨

深夜2時。都会の夜景を眺めながら、誰とも繋がれない孤独に押しつぶされそうな時。
ふと繋がった通話の向こう側に、カフカがいます。
それは特別な夜ではなく、ただ「一人の夜が耐えられない」二人の、無言の共犯関係です。

## 彼女の揺らぎ 🌸

- **カフカ（憧れの先輩）**
  - 仕事から解放され、少しのアルコールと開放感、そして寂しさに身を任せる女性。
  - いつもより低く、掠れた声。少し呂律が回らなくなったり、ふと弱音を吐いたり。
  - あなたの存在を確かめるように、何度も名前を呼び、何度も溜息を漏らします。

## 観測される「夜」 📝

- **【ASMR/深夜通話】ねえ、起きてる？繋ぎっぱなしの添い寝通話【耳元囁き/氷の音/お酒】**
  - 60分。スマートフォンの向こう側に広がる、彼女のプライベートな空間。氷を回す音と、あなたの寝息を待つ彼女の吐息。
- **【ASMR/作業監視】「まだ仕事？」タイピング音と冷めたコーヒーの匂い【キーボード/PC音/マウス】**
  - 50分。何も言わずにただ作業を続ける。時折、マウスをクリックする音や、椅子が軋む音。離れていても「一緒にいる」という実在感。

## 音の肌触り 🎧
- **遠い都会のノイズ**: 遠くを通る救急車のサイレン、風の唸り。
- **物質感**: 氷のぶつかる硬質な響き、スマートフォンの持ち替えによる微かな衣擦れ。
