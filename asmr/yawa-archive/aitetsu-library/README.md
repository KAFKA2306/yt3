# 📚 藍鉄図書館 (Aitetsu Library)

「消えゆく『感触』を、この手の中に。」

## ここに宿るもの ✨

すべてがデジタルに溶けていく世界で、忘れ去られた紙の重みとインクの匂いを守る書庫。
カフカは、消えゆくものを愛し、それを手放せない「執着」の象徴です。
埃の舞う静寂の中で、彼女はあなたという「記録」を、誰にも知られずに書き留めます。

## 彼女の揺らぎ 🌸

- **カフカ（司書）**
  - 言葉よりも、紙とペンを愛する孤独な女性。
  - 不器用な朗読、震える指先、ふとした溜息。
  - 「忘れないで」という祈りが、彼女の全ての動作に宿っています。

## 観測される「夜」 📝

- **【ASMR/読書】藍鉄図書館で眠るまで、古い物語を読み聞かせて【朗読/紙の音/睡眠導入】**
  - 60分。単なる朗読ではなく、カフカが隣でページを捲り、時折内容について迷ったりする「実在する時間」の提供。
- **【ASMR/掃除】書庫の整理、埃を払う音と小さな相談事【掃除の音/囁き/二人きり】**
  - 45分。はたきのパタパタという音、古い梯子が軋む音。日常の中に潜む、壊れそうなほど繊細な親密さ。

## 音の肌触り 🎧
- **物質の崩壊**: 擦れた紙、乾いたインク、軋む木製家具。
- **時間の余白**: 何も喋らない、ただ本を整理するだけの長い沈黙。
