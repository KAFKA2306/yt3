# 🌧️ 雨音避難所 (Amaoto Shelter)

「世界が消えるまで、ここを離れないで。」

## ここに宿るもの ✨

豪雨のアパート。古いラジオのノイズ。
ここは、外部との接続を断たれた、二人だけのサンクチュアリです。
効率や数値、明日への不安……そういったものをすべて雨が洗い流すまで、カフカがあなたを抱きしめ、匿い続けます。

## 彼女の揺らぎ 🌸

- **カフカ（幼馴染）**
  - ぶっきらぼうで不器用。でも、あなたの鼓動が速くなることに誰よりも敏感な女の子。
  - 「嫌なら帰れば？」と言いながら、雨戸を固く閉ざしてあなたを帰さない。
  - 声は少し高揚し、耳元では熱を帯びる。その不安定な「熱量」をアーカイブします。

## 観測される「夜」 📝

- **【ASMR/添い寝】雨音のシェルター、一枚の毛布で温まる夜【耳元囁き/心音/密着】**
  - 60分。外の激しい雨音と、毛布の中の「二人の密閉感」。衣擦れと心音が混ざり合う、極限の親密さ。
- **【ASMR/作業】一緒に課題やる？雨の日の静かな勉強机【ノートの音/鉛筆/微かな息】**
  - 50分。何も話さなくても、隣でペンが走る音だけで繋がっていられる。沈黙の中にある「相互監視」の安心感。

## 音の肌触り 🎧
- **雨の深度**: 屋根を叩く鋭い雨音から、排水溝に吸い込まれる鈍い音まで。
- **密閉された音**: 毛布の中の籠もった声、耳元のダイレクトな囁き。
