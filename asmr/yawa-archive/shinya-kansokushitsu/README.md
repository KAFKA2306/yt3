# 🔭 深夜観測室 (Shinya Kansokushitsu)

「観測し続けること、それは究極の執着。」

## ここに宿るもの ✨

誰もいない、高い丘の上の観測室。
星を数えるように、あなたの呼吸を、あなたの動きを、カフカは記録し続けます。
この部屋の静寂は、単なる音の欠如ではなく、一音も聞き漏らさないための「研ぎ澄まされた集中」です。

## 彼女の揺らぎ 🌸

- **カフカ（観測員）**
  - 理性的で無機質。しかし、その裏側に狂気的なまでの「執着」を秘めた女性。
  - ペンの運びが乱れたり、あなたの気配を追うために呼吸を止めたり。
  - 感情を押し殺した声の震えが、何よりも多くを語ります。

## 観測される「夜」 📝

- **【ASMR/囁き】深夜の天体観測、星の名前を教える君の隣で【耳元囁き/書き込み音/静寂】**
  - 45分。静寂を切り裂くような鋭いペン音と、鼓膜に直接触れるような密やかな囁き。
- **【ASMR/心音】脈打つ記録、君の存在を確かめるために【心音/衣擦れ/密着】**
  - 60分。ただ静かに重なる、二人の心臓の音。カフカの「独占欲」が音になって溢れ出す、濃密な時間のアーカイブ。

## 音の肌触り 🎧
- **微細な生体音**: 唾液を飲み込む音、心音、まばたき。
- **冷たい静寂**: 広い部屋の残響と、そこにある「不在」を感じさせる空間設計。
