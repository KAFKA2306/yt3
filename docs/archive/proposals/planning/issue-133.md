対象: GitHub Issue #133 「動画企画: 日銀が利上げしたのに、なぜ1ドル159円？ 152→159円で円安の正体を分解する」
基準日: 2026-09-24（Issue 記載）。制作時は `as_of` を付けて最新値へ更新する。
本書は企画・検証計画のみ。データ取得、動画制作、公開は行っていない。

## 1. 企画の中心命題

為替は「現在の政策金利」だけでなく「次にどちらがどれだけ動くと市場が予想しているか」で動く。
動画では「利上げ = 円高」の単一因果を否定し、次の要素に分解する。

- 日米の現在の政策金利
- 将来の政策金利パス（先物 / OIS が取得できる場合）
- インフレと長期金利
- キャリートレードと需給（ポジショニングは定量データがある場合のみ）
- 為替介入の警戒

断定はしない。「日本円に価値がない」「160円なら介入」などは使わない。
