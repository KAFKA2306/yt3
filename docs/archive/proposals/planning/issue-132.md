# Issue #132 企画・検証計画: 自動運転で価値が増幅する「資本」は何か

対象: GO (581A) / 大和自動車交通 (9082) / ヴィッツ (4440) / マクニカHD (3132)
性格: 投資推奨ではなく、企業価値の源泉を「資本」の観点から分解する構造仮説の動画。
製作プロファイル: 秒算マネー (`byosan`)

## 1. 中心命題

- 問い: 市場は自動運転AIそのものを買っているのか。それとも顧客・営業拠点・安全技術・社会実装力を持つ会社を買っているのか。
- 仮説: 自動運転の普及で価値が増幅するのは、既存の「再利用可能な希少資本」を持つ企業。
- 「10倍」は株価予測ではなく、資本価値が増幅する構造仮説として扱う。
