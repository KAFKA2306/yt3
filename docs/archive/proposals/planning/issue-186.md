作成日: 2026-10-10
ステータス: 企画・台本設計のみ。動画の生成・公開は未実施。

## 1. 結論

- 視聴者は「HBMは速いが小さい。SSDは大きいが遅い。その間を埋める層が増えている」を説明できれば成功とする。
- 冒頭は専門用語を使わず「机・棚・倉庫」で始め、数値は帯域と容量の意味を説明した後に出す。
- 数値は規格値・試作値・製品値を必ず分けて表示する。HBF 3.072TB/s は量産実測値として扱わない。
- 本文書の数値は Issue 本文の記載であり、一次ソースを本作業では再取得していない。公開前に全数値の再検証が必要（§9）。

## 2. 視聴者と前提

- 想定: DRAM / NAND / HBM / 帯域 / IOPS / PCIe / UCIe / CXL を知らない視聴者。
- 専門用語は初出時に一文で意味を説明する。
- 最初の2分で理解させる範囲は「速い・小さい机」「大きい倉庫」「その間の棚」の3概念のみ。

## 3. 比喩の固定

| 比喩 | 実体 | 役割 |
|---|---|---|
| 机 | HBM（HBM4E） | GPUの隣。すぐ取れるが置ける量が少ない |
| 棚 | HBF（Grade 3 規格値） | HBMより大容量、HBM級の帯域を狙うNAND層 |
| 冷凍庫・大型収納 | KIOXIA 高帯域Flash（試作） | 容量重視の別ルート |
| 倉庫 | NVMe SSD（CM9-R） | 大容量・ストレージ |

「帯域」の説明は「1秒間に運べるデータ量（道路の車線数に近い）」とし、TB/s を出す前に毎秒何GBかに戻して言い換える。

## 4. 数値表（成熟度タグ付き）

| レイヤー | 技術 | 容量 | 帯域 | 成熟度タグ | 注意 |
|---|---|---:|---:|---|---|
| L0 | HBM4E | 12-high 48GB / 16-high 最大64GB | 最大4.0 TB/s（16-high） | SAMPLE / 製品ロードマップ | 12-high は 3.6 TB/s。容量と帯域を別SKUで混ぜない |
| L1 | HBF Grade 3 | 最大512GiB | 3.072 TB/s | SPEC（OCP HBF v0.7.0） | 量産実測値ではない。Grade 1/2/3 = 0.384 / 1.536 / 3.072 TB/s |
| L4 | KIOXIA 高帯域Flash | 5TB | 64 GB/s | PROTOTYPE（2025年試作・動作実証） | 128Gbps PAM4 はコントローラ間指標で、64GB/s とは別物 |
| L5 | KIOXIA CM9-R 61.44TBモデル | 61.44TB | 13.5 GB/s（Sequential Read） | PRODUCT | 14.8GB/s は 30.72TB 等の別モデル。組み合わせない |
| 別枠 | KIOXIA GP1 | 非掲載 | 非掲載（IOPSが指標） | 評価サンプル予定（2026年末） | 最大1,000万 Random Read IOPS（512-byte）。帯域グラフに載せない |

注記:
- 単位は原文表記を保持する。512GiB ≒ 550GB、5TB = 5000GB と換算する場合は動画内で明示する。
- 比較倍率は換算後の値で計算し、「約8倍」は GiB/GB 混在の概算であることを台本に残す。

## 6. 視覚素材の仕様

1. **机・棚・倉庫図**: 第3節の比喩表をそのまま図にする。Visual 4 より先に見せる。
2. **容量×帯域の対数プロット**: X=容量、Y=帯域、両軸対数。点は HBM4E / HBF Grade 3 / KIOXIA 5TB試作 / CM9-R 61.44TB。GP1 は帯域未公表のため載せず、脚注で除外理由を書く。成熟度タグは点のラベルに含める。
3. **成熟度タグ**: 各数値の横に SHIPPING / SAMPLE / SPEC / PROTOTYPE / PRODUCT のいずれかを必ず付ける。
4. **AIメモリ階層図**: GPUからの距離で縦に並べる。NAND/DRAM の分類は補助表示にとどめる。
   ```
   GPU
   ├ HBM       超高速 / 小容量
   ├ HBF       HBM級帯域 / 大容量（規格値）
   ├ 高速Flash TB級（試作）
   └ NVMe SSD  数十TB / ストレージ
   ```
   図作成は既存の図解ツール（drawio 等）を優先する。ツールは本作業では選定していない。
