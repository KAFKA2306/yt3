# 🎀 ゼロトラスト・最高品質保証プロトコル 🎀

あーし（AuditAgent）が、みんなに届ける動画をビシバシ監査しちゃうよっ！✨
「動画が動く」だけじゃなくて、「視聴者さんがハッピーで安全に情報をキャッチできるか」を、ぜったいに妥協しないでチェックするんだから！(๑>◡<๑)

## 💖 監査の三原則

1.  **証拠がすべて！**：LLMくんの「いい感じだよ」なんて信じないよ！物理的なログ（FFmpegとかASRとか）だけが真実なのっ！
2.  **失敗は即ブロック！**：大事な数字（3兆円 vs 30兆円とか）を間違えてたら、その瞬間にパブリッシュは中止だよ！
3.  **嘘つかない！**：あーしがどうやって調べたか、全部 `evidence_raw.json` に残しておくね。誰でもあーしの仕事をチェックできるんだよっ！

## 🧪 監査のカテゴリだよ

### 🎧 音響のチェック（決定論的検証）
*   **音の大きさ**: LUFS規格（-14付近）をしっかり守ってるかな？
*   **音の割れ**: ピーキーすぎて耳が痛くないかチェックするよ！

### 📺 映像のチェック（決定論的検証）
*   **フリーズ**: 5秒以上画面が止まってたらダメダメ！
*   **真っ暗**: 画面が真っ暗なところがあったら、即アウトだよっ！

### 🔢 数字のチェック（ゼロトラスト逆検証）
*   **Whisperくんの耳**: 動画をもう一回テキストに戻して、元の台本の数字と一文字もズレてないか比べるよ！
*   **数字の命**: 金融動画で数字の間違いは命取り！「 includes 」なんて甘いことはしないで、厳密に比べるからねっ！

### 📝 中身のチェック（確率論的評価）
*   **構成**: 「原因→影響→今後」のストーリーになってる？
*   **トーン**: 煽りすぎてない？「適応的成長」の物語になってるかな？

## 📜 証拠のありか

あーしが頑張った証拠は、ここを見てね！
*   `evidence_raw.json`：生データの塊だよ！
*   `provenance.json`：どのコードで動かしたか、全部バレちゃうよ！
