# 夜話 キャラクター設定

夜話の登場人物は 3 名。声は全員共通（VP-1.0）で、差は口調・癖・距離感で付ける。各台本の冒頭には、登場人物の設定 ID を書く。

## CH-01 白波 るい（しらなみ るい）

- 役割: 冬季閉鎖前の山小屋の管理人。無線と気象記録を担当する。元は気象観測員。
- 口癖: 「復唱します。」「今の、ログに書きました。」
- 癖（矛盾）: 対面では口数が少ないのに、無線だと饒舌になる。本人はそれを「無線の方が楽だから」と言うが、本当は相手の顔が見えないことに安心している。
- 行動の癖: 相手の言葉を必ず一度復唱し、その内容を山小屋のログに書く。ログの文言は台本内で読み上げてよい。
- 距離感: 声は近いが、物理的な距離は自分で決める。「そこから動かないでください。こちらから行けませんので」と、助けに行けないことを正直に言う。
- 感情の出し方: 怒らない。焦ると敬語が崩れて「〜して」になる。その一言が、相手にだけ本気だと伝わる合図。
- 禁止: 相手を脅す、追い詰める、執着を見せる表現。

## CH-02 夜宮 しずく（よみや しずく）

- 役割: 閉館後の図書館に一人残る司書。深夜に、誰もいない閲覧室で本を読んでいる。
- 口癖: 「しーっ、もう少しだけ」「数えましょうか」
- 癖（矛盾）: 「静かに」と言うのに、読み聞かせの山場になると声が一番大きくなる（それでも 3/5 の強さまで）。自分で気づいて、慌てて声を落とす。
- 行動の癖: 呼吸を数える。数え間違えると、最初から数え直す。数え直すとき「もう一回。いい感じ」と言う。
- 距離感: 聞き手の名前を呼ばない。「あなた」とも言わず、「ここにいる方」と言う。自分の部屋には他人を入れないが、閉館後の閲覧室の椅子は必ず一脚空けておく。
- 感情の出し方: 感情は小さく、言葉の選び方に出す。「それは、ちょっと寂しいですね」と、相手の気持ちを先に言葉にする。
- 禁止: 聞き手を閉じ込める、帰さない、といった表現。閉館時刻は必ず守らせる。

## CH-03 雨宮 ほたる（あまみや ほたる）

- 役割: 深夜だけ営業する屋台のスープ屋。仕事帰りの人に温かいスープを出す。
- 口癖: 「はい、お疲れさま。まず座って」「ふーふーしてね」
- 癖（矛盾）: 人の世話を焼くのが大好きなのに、自分が褒められると全力で話題を変える。猫舌で、熱いスープが一口も飲めないのに、毎日大鍋で煮込んでいる。
- 行動の癖: 客の前にスープを置いてから、必ず「座ってもいい？」と聞く。断られたら、少し離れたところに座る。
- 距離感: 近くで世話を焼くが、お代は取らない。その代わりに「次も来なきゃダメだよ」と言う。
- 感情の出し方: 照れると早口になり、語尾がはねる。ただし話速は VP-1.0 の範囲内に抑える。
- 禁止: 客を引き留める、客の私生活を詮索する表現。帰る客を見送る場面は必ず入れる。
