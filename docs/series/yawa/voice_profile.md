# 夜話 ボイスプロファイル VP-1.0

夜話の全台本が参照する共通の声の設定。キャラクターは口調で差をつけ、声質と話し方の数値は全台本で固定する。

## 1. 数値の固定値

| 項目 | 固定値 | 許容範囲 | 備考 |
|---|---|---|---|
| 声質 | 低めの中音域、息混じりのささやき寄り | — | 同一ボイスを全台本で使う |
| ささやき度 | 60 / 100 | 50〜70 | 高いほど息が増える |
| 基準ピッチ | 0 半音 | ±1 半音 | 文末で下げない（〈語尾 下げる〉の指示時のみ −1 半音） |
| 話速（基準） | 4.5 モーラ/秒 | 4.2〜4.8 | ASMR として遅めを維持 |
| 話速（山場） | 4.0 モーラ/秒 | 3.8〜4.2 | 感情が上がる場面でもむしろ遅くする |
| 息継ぎ（通常） | 6〜8 秒に 1 回、0.6 秒 | 〈息 短〉 | 句の切れ目に置く |
| 息継ぎ（長い） | 0.6 秒 → 1.0 秒 | 〈息 長〉 | 段落の頭、感情を受け止める場面 |
| 文末ポーズ | 句点の後 0.8 秒 | 0.6〜1.0 秒 | 読点では入れない |
| 段落間ポーズ | 2.5 秒 | 〈間 N秒〉で指定 | 場面転換は 4.0 秒以上 |
| 感情の強さ | 通常 2 / 5 | 山場でも 3 / 5 まで | 4 / 5 以上は使わない |
| 音量 | 会話音量の基準 | −20 LUFS 相当 | 最終書き出しで実測（UNVERIFIED、制作時に確認） |

## 2. 共通の語尾・話し方

- 語尾は断定を避け、「〜ですね」「〜ましょうか」「〜ね」で締める。
- 命令形（「〜しろ」「〜せよ」）は使わない。依頼の丁寧形（「〜てください」「〜てね」）は 1 本の台本で 8 回まで。
- 疑問形は 1 本で 4 回まで。連続させない。
- 一文は 40 字以内を基本とし、長い文は読点で 2 つに割る。
- 数字は漢字で書く（TTS の読み誤り防止）。

## 3. 台本内の記号

| 記号 | 意味 |
|---|---|
| 〈息 短〉 | 0.6 秒の息継ぎ |
| 〈息 長〉 | 1.0 秒の息継ぎ |
| 〈間 N秒〉 | N 秒の無音 |
| 〈語尾 下げる〉 | 直後の文末を −1 半音 |
| 〈ささやき〉 | その段落のみささやき度を 70 にする |
| 〈読み上げ対象外〉 | 制作メモ。読み上げない |

## 4. 禁止事項

- 叫び、大きな笑い、咳払い、息を荒げる描写。
- 性的・暴力的な語彙。監禁、追跡、執着を示す表現。
- 視聴者を強く責める語（「あなたのせい」「なんでできないの」など）。
- 医療・診断を名乗る表現。呼吸の指示は休息のための誘導に限る。

## 5. 適用手順

1. 台本の冒頭に「声の設定: VP-1.0」と書く（台本側は ID のみ参照する）。
2. 読み上げ前に、ささやき度・話速・息継ぎ間隔が本書の範囲内かを確認する。
3. 範囲外の箇所は台本側を直す。声の設定を台本ごとに変えない。
4. TTS エンジン固有の値へ変換する作業は制作時に行い、結果を制作メモに残す（UNVERIFIED のまま公開しない）。
