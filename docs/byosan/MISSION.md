# 秒算マネー

秒算マネーは、金融・投資・企業・経済の動きを、日本語の視聴者が「続きが見たい」と思う動画にする。

## 作品づくり

毎回、今日取り上げる意味と、その題材ならではの見どころを見つける。視聴者が見終えた時に、新しい理解、発見、問いの答え、考え方の変化のどれかを持ち帰れる作品を目指す。

企画AIが作品ごとに、題材、視点、話し方、台本の流れ、尺、タイトル、画面表現を選ぶ。問い型タイトル、決まった章立て、二人の掛け合い、家計への接続、数字の個数、感情の流れ、行動提案は必須にしない。同じ作り方を続けず、素材に合う表現を選ぶ。

## 信頼

数字、期間、定義、出典を入力資料に合わせる。実績、推計、見通しを区別し、根拠のない因果や家庭への換算を足さない。限界や不確実さは、理解に必要な場所で自然に伝える。

## 参考と学習

他の媒体からは、題材の発見、説明の明快さ、視聴者を引き込む工夫を学び、表現や結論は独自に作る。公開後の視聴維持、クリック率、コメントは次の企画を考える材料にする。数字だけで作品を採点したり、自動で却下したりしない。
