# MISSION.md | 秒算マネー

> **ニュースを追うな、仕組みとレジームを解剖せよ。—— 一次資料と市場計器で「なぜそうなったか」を腑に落とす金融・経済ドキュメンタリー。**

- Product: `byosan`
- Scope: チャンネルの編集方針、2 柱制作（構造ドキュメンタリー＋レジーム転換解剖）、収益化・品質原則、成果指標。正準コマンドと公開権限は `AGENTS.md` が持つ。

## 1. 存在理由と視聴者への約束

米国株・日本株・AI・半導体・マクロ経済を追う日本語の個人投資家・ビジネス層に向けて、ニュースの読み上げや煽りではなく、**「今なぜこの仕組みが動いたのか／相場のレジームがどう切り替わったのか」を一次資料と動くデータ図解で解き明かす**。

- **未確認の噂は動画に載せない**: タイムライン上の裏付けのない噂や憶測は、制作前のリサーチ段階で切り捨てる。動画内で「未確認です」と連呼せず、**確認できた価格・決算・統計・歴史比較だけで 100% 面白くする**。
- **毎日穴埋め投稿をしない**: 何も起きていない日に小粒記事で日次投稿すると CTR 低下と YouTube の Inauthentic Content 判定を招く。出す価値がある本数だけに集中する。

## 3. パッケージと表現

- **冒頭 10 秒の数字・矛盾フック**: 挨拶や前置きを省き、衝撃の数字・構造的矛盾・レジーム変化の核心から入る。
- **一次資料の証拠画面と動く図解**: 決算書・統計・価格推移の一次データを見せ、OpenMontage / Remotion の動くデータ図解で視覚的に腑に落とす。
- **投資助言の禁止**: 「今すぐ買え」「暴落確定」「爆益」等の断定や売買推奨を行わない。AI ペルソナによる金融助言ペナルティを避け、仕組み・現在地・歴史比較に徹する。
- **AI 開示**: 必要に応じて合成メディア開示を適切に行う。

## 4. 成功指標（YPP・視聴者獲得）

- **収益化マイルストーン**: YouTube パートナープログラム本収益化（登録者 1,000 人・直近 365 日の長尺再生 4,000 時間）と広告適合（緑アイコン・高 RPM）の維持。
- **先行 KPI**: サムネイル CTR、冒頭 30 秒維持率、平均視聴維持率、1 動画あたり登録増。指標の定義と算出正本は [Star Schema & dbt Standard](../standard/star-schema-standard.md) および `analytics/models/marts/mart_channel_growth_kpi.sql` に置く。
- **データ還流**: `task analytics:refresh` と `task analytics:build` で更新した実績を定期的に確認し、伸びた題材・尺・パッケージを次の企画設計へ生かす。単一の数値だけで作品を自動却下しない。
