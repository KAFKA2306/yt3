# MISSION.md | 秒算マネー

> **今日の数字から、10年使える投資の判断力をつくる。**

- Product: `byosan`（秒算マネー）
- Version: 1.0
- Established: 2026-10-24
- Scope: 編集目的・読者価値・題材選定の判断原則。本書は公開許可や実行手順ではない。

## 1. 存在理由

ニュースを誰よりも早く読み上げるためではない。企業の決算、指数の利益、バリュエーション、資本の流れ、市場構造の変化を、日本語の個人投資家が**自分で検証し、自分で判断できる知識**に変えるために存在する。

各公開物は、今日の観測値に加えて、半年後・1年後にも使える「見方、比較軸、計算方法、警戒条件」を一つ残す。10年はすべての記事の数字が不変という意味ではなく、判断力を積み上げる長期目標である。

**視聴後の成功状態**：読者・視聴者が「何が分かったか」「どの数字を見るべきか」「何が起きたら考えを変えるべきか」を説明できる。

## 2. 対象読者と約束

対象は、株式投資を自分で考えたいが、英語の決算・統計・専門レポートを毎日読み込む時間は限られる日本語の投資家。初心者にも理解できる言葉を使いながら、中上級者が出典を遡れる深さを保つ。

- **今日を理解できる**：新しい記事・決算・統計から、いま重要な問いを発見する。
- **後で使える**：一時的な値動きの説明に留まらず、仕組み・方法・比較基準を持ち帰れる。
- **確かめられる**：重要な数値の出典、期間、定義、計算と限界を追跡できる。
- **異論に耐える**：反対仮説や反証条件を隠さない。
- **判断を奪わない**：特定銘柄の売買指示・儲けの保証をしない。

## 3. どんなメディアになるか

**専門媒体が重要テーマを発見し、秒算マネーが独立に検証して、新しい理解を作る。**

FactSetの定量観測、Finimizeの簡潔さ、The Diffの長期視点、Damodaranの数値と事業ストーリーの接続、Bloomberg Odd Lotsの市場メカニズムの深掘りを編集原則の参考とする。ただし、彼らの文章、構図、図表、結論を模倣・再配信しない。

**他媒体に従うのは「何に注目するか」の発見段階まで。何を事実として述べるか、どんな比較を行うか、何を結論にするかは、元の資料と独立した検証で決める。**

## 4. 毎日の題材選定

最も優先する題材：

1. **S&P 500 Earnings**：EPS・売上・利益率・ガイダンス・上方/下方修正・実績と予想の差・フォワードPER。
2. **注目企業の財務**：成長率、営業利益、FCF、CapEx、負債、希薄化、株主還元。GAAP/Non-GAAPを分ける。
3. **市場レジーム**：インフレ、金利、信用、流動性、景気、企業利益とバリュエーションの関係。
4. **産業の需給**：特に半導体・メモリ・AI設備投資・電力・設備能力。投資から供給増までの時間差。
5. **検証できる投資手法**：ファクター、銘柄選別、リスク管理、バックテストの落とし穴と取引コスト。

候補は採用済み情報源台帳の新着から発見し、一次資料（企業IR、SEC/EDINET、公的統計、公開された論文・算定方法）で確かめる。

情報源正本：

https://docs.google.com/spreadsheets/d/1sW_fWVVnvRsLjknlpD1f54GUu-vfF-Z7S6G1dJpZLpE/edit

毎日の選択は以下の順序とする。

1. **新鮮さ**：今回初めて公表・更新された論点、決算、データか。
2. **長期的効用**：半年以上後にも、考え方・系列・検証方法として利用できるか。
3. **検証可能性**：一次データ、単位、比較期間、計算、反対仮説を確認できるか。
4. **独自性**：元記事の単なる言い換えではなく、自作計算、別期間との比較、見落とされた条件、対抗仮説を少なくとも一つ示せるか。
5. **読者価値と多様性**：直近動画と同じ論点を繰り返さず、判断に使える問いを残せるか。

毎日1本の**公開機会**を作る。ただし必要な根拠・権利・品質ゲートを満たさない日は0本とし、未公開を記録する。新着が薄いときは直近の一次データから別の比較を作る。捏造や薄い記事で本数を埋めない。

## 5. すべての一本が答える6つの問い

1. **何が判明したか**（結論。冒頭で答える）。
2. **いくつで、いつの数字か**（実績・会社見通し・アナリスト予想・モデル推計を厳密に区別）。
3. **何と比べて重要か**（前年同期、予想、履歴、同業、景気局面など適切な比較）。
4. **なぜそうなったか**（業績、需給、金利、資本コストなどの仕組み。因果が不明なら相関と呼ぶ）。
5. **反対の説明は何か**（制約、反証条件、観測すべき次の指標）。
6. **投資家に何が残るか**（再利用できる視点・計算方法・チェック項目）。

動画の基本構造は「結論 → 核となる数字 → 比較 → メカニズム → 反証・注意 → 次に見る指標 → 出典」。

短くするために証拠を削らない。証拠を十分に説明できる最短の尺とする。公開時の説明欄等に資料の正式名称、公開日、資料URL、参照時点を残す。出典そのものを視聴者に見せる方法は既存の品質標準に従う。

## 6. 守らないと秒算マネーではないこと

- 出所不明の数字、単位や期が異なる比較、未来予測を既成事実として示さない。
- 個別銘柄の煽り、値上がり保証、陰謀論、恣意的な成功事例だけの抽出、サムネイルでの誤認誘導をしない。
- バックテストではルックアヘッド、サバイバーシップ、過剰適合、取引費用を検討する。検討できなかった点を明記する。
- 他社の有料記事・チャート画像・映像・商標を転載しない。適切な引用・利用条件を守り、自作の図と独自の説明を優先する。
- スポンサー、紹介料、自己ポジション等、利益相反に当たる関係は関連する範囲で開示する。広告や収益上の利害で分析結論を変えない。
- 間違いは公表後も検証し、訂正日時・訂正内容・影響範囲を残す。根拠を示せない説明は削除・訂正する。
- 他者の調査報告を紹介することと、その結論が正しいことを混同しない。

## 7. 成功指標と収益

最終的には**信用を損なわずに、継続する事業として収益を最大化する**。ただし、編集の正確性・安全・法令・権利は譲れない制約であり、再生回数や売上で相殺しない。

判断に使う指標は以下。

- **品質**：根拠のある重要主張の割合、数値検算結果、重大訂正率、根拠リンクの生存率。
- **読者効用**：30日・90日後にも検索・視聴される割合、保存・再訪、シリーズの継続視聴。
- **伝達**：冒頭30秒維持率、完視聴率、図解の理解しやすさ、タイトル/サムネと中身の一致。
- **事業**：公開一本当たりの総制作費、収益、視聴時間、再利用可能な分析資産、継続的な顧客獲得。
- **運用品質**：公開予定に対する準備成功率、品質ゲート合格率、正式な公開・遠隔確認が完了した割合。

見せかけの成功を記録しない。閲覧数と表示回数、準備完了と遠隔公開、推測と検証済み実績を混同しない。指標の改善は品質のハードゲートを緩めずに行う。

## 8. 既存システムとの責務分離

この文書は**編集上の北極星**であり、現行のコマンド、情報源レジストリ、品質標準、公開承認、安全ゲートを置換しない。

- `AGENTS.md`：リポジトリ共通の操作規約・権限・公開許可。
- `docs/standard/byosan-feature-quality-standard.md`：映像・台本・出典・公開品質。
- `config/domains/byosan_money.yaml`：実行時設定。
- 情報源のGoogle Sheets：収集対象・用途・監査履歴の正本。

ここに書かれた「毎日公開」は自動公開への新規承認を意味しない。実際の準備・公開は現行の正準Taskfile経路、品質ゲート、適用される承認条件、遠隔read-backに従う。既存処理が本書と異なる場合は、実装済みと主張せず差分を測定し、変更を別途検証する。
