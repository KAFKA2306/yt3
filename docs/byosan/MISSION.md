# MISSION.md | 秒算マネー

> **世界の企業・AI・マクロ経済の「数字の裏にある構造」を、一次資料と歴史比較で腑に落とす。**

- Product: `byosan`
- Scope: チャンネルの編集方針、2レーン運用、収益化・品質原則、成果指標。正準コマンドと公開権限は `AGENTS.md` が持つ。

## 1. 存在理由と視聴者への約束

米国株・日本株・AI・半導体・マクロ経済を追う日本語の個人投資家・ビジネス層に向けて、「ニュースの表面の要約」ではなく**一次資料の数字と構造が繋がる一本**を届ける。

視聴者が見終えたときに、次のいずれかを持ち帰れる作品を目指す。
- 決算や統計の数字が「なぜそうなったか」の構造的理解
- 過去のバブル・暴落・産業転換との比較から得られる判断軸
- 話題の企業・技術（AI、半導体、クラウド、金融市場）の勝ち筋と死角の整理

## 2. 2レーン制の制作方針

量産による再生分散と YouTube の Inauthentic Content 判定を避け、**資産になる大型特集**と**鮮度の高い厳選ニュース**を明確に分けて運用する。

| レーン | 目標頻度 | 尺の目安 | 企画の入口と狙い |
| --- | --- | --- | --- |
| **A. 大型テーマ特集（登録・総再生時間の柱）** | 週2〜3本 | 8〜15分 | オーナー起案の特集企画・検証済み Fact Sheet（例：AI投資と鉄道バブル、半導体・CUDAの堀、歴史的暴落パターン、決算構造比較）。検索・関連動画で長期再生される資産動画を作る。 |
| **B. 日次の厳選ニュース解説（接点・鮮度の柱）** | 1日1本（毎朝 07:00 JST） | 3〜6分 | `discovery` 記事群から**日本語の個人投資家・テック層が関心を持つ大型企業・半導体/AI・マクロ・市場構造**を優先して選ぶ。ニッチな個別企業の小粒記事は他に有力題材がある限り採らない。 |

## 3. パッケージと表現

- **タイトルとサムネイル**: 数字の対比、常識とのズレ、具体的な固有名詞（企業名・指数・指標名）で「なぜ今見るべきか」を最初に伝える。誇張や釣りはしない。
- **作品ごとの設計**: 企画AIが題材に合う構成・語り口・図解を選ぶ。決まった章立て、掛け合い、家計換算、結論先出しのテンプレを強制しない。
- **Shorts 展開（任意）**: 大型特集の核心パート（30〜60秒）を切り出して新規視聴者への入口に活用する。

## 4. 信頼と YouTube 収益化原則

- **投資助言の禁止**: 「今すぐ買え」「暴落確定」「爆益」等の断定や投資推奨を行わない。YouTube の AI ペルソナによる金融助言リスクを避け、一次資料の事実・前提・複数シナリオの解説に徹する。
- **一次資料との一致**: 数字、期間、定義、出典を入力資料に合わせ、実績・推計・見通しを明確に区別する。根拠のない因果や家庭換算を足さない。
- **AI 開示**: 必要に応じて合成メディア開示を適切に行う。

## 5. 成功指標（YPP・視聴者獲得）

- **収益化マイルストーン**: YouTube パートナープログラム本収益化（登録者1,000人・直近365日の長尺再生4,000時間）と広告適合（緑アイコン）の維持。
- **先行 KPI**: サムネイル CTR、冒頭30秒維持率、平均視聴維持率、1動画あたり登録増。指標の定義と算出正本は [Star Schema & dbt Standard](../standard/star-schema-standard.md) および `analytics/models/marts/mart_channel_growth_kpi.sql` に置く。
- **データ還流**: `task analytics:refresh` と `task analytics:build` で更新した実績および `data/memory/byosan_money/performance_summary.json` を定期的に確認し、伸びた題材・尺・パッケージを次の企画設計へ生かす。単一の数値だけで作品を自動却下しない。
