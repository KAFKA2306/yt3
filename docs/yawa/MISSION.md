# MISSION.md | 夜話アーカイブ ASMR

> **推しの声と距離感に何度でも会いに来られる、全年齢向けシチュエーションボイス劇場。**

- Product: `yawa`
- Scope: チャンネルの編集方針、固定キャスト制、ビジュアル・音響方針、広告適合ライン、成果指標。正準コマンドと公開権限は `AGENTS.md` が持つ。

## 1. 存在理由と視聴者への約束

アニメ・声優・DLsite/BOOTH 文化に親しむリスナーに向けて、一日の終わりに**「またこの人の声を聴きたい」と戻ってこられるシチュエーションボイス**を届ける。

毎回使い捨ての声と設定を作るのではなく、**少数の看板キャラクター（固定キャスト）**の声・立ち姿・関係性を積み上げ、ファンと登録者が育つチャンネルを作る。

## 2. 固定キャスト制とジャンル設計

- **舞台と世界観（同じ街 × 少し幻想的な非日常）**:
  - 3人は駅前通りの一本裏、夜だけ開く少し不思議な古本喫茶「夜話（よわ）」がある**同じ街**で暮らしている。
  - 日常の延長（仕事帰り・雨宿り・休日の寄り道）に、少しだけ幻想的な要素（不思議な古本や手紙、時を忘れる夜の空気、街の小さな噂）が混じる温かな夜話劇を届ける。たまに他キャストの名前や差し入れが話題に上る緩やかな繋がりを持つ。
- **固定キャスト正本**: [characters.json](characters.json) に定義する 3 名の成人キャラクターを看板キャストとする。
  - **日向 はるか（`haruka`）**: 距離の近い幼なじみ／同僚系。軽快な掛け合い・日常コメディ・照れ。
  - **白瀬 しずく（`shizuku`）**: 少し不器用で世話焼きな先輩系。仕事終わりの労い・ツンデレ気味の気遣い・寄り道。
  - **月島 なお（`nao`）**: 落ち着いた聞き役の夜間カフェ兼古本屋の店主。雨宿り・静かな雑談・少し不思議な夜話。
- **声の一貫性**: 各キャラクターは専用の参照音声（`data/state/yawa/references/<character_id>.wav`）を初回生成して永続利用し、エピソードをまたいでも同じ人物の声として認識できるようにする。場面ごとの感情は台詞と `acting` で自然に動かす。詳細は [声の嗜好と演技基準](voice-preferences.md) を参照。
- **脱・深夜ケア一辺倒**: 直近エピソードのキャストと題材を参照し、同じキャラや「終電後＋弱音＋寝かしつけ」の反復を避ける。日常コメディ、軽快な掛け合い、寄り道・非日常、静かな労いを意図的にローテーションする。

## 3. 再生リストの入口

- **キャラクター別**: はるか・しずく・なおの各リストを、その声や距離感にまた会いに来る入口にする。複数キャスト回は登場した各キャラクターのリストに入れ、新しい回を先頭に置く。
- **連作別**: 続きものは専用リストにまとめ、第1話から順に並べる。概要で「初めての方は第1話から」と案内し、各話が公開された時点で追加する。
- チャンネルの動画一覧を全作品の時系列アーカイブとして使う。単話を重ねた全話リストは作らず、キャラクターを選ぶか、物語の順を追うかの二つの用事に絞る。
- 固定キャストIDの記録がない過去回はキャラクター別リストへ推測で入れず、動画一覧に残す。
- 正本は `docs/yawa/characters.json`（キャラクター別の名前・説明）と `docs/yawa/series/*.json`（連作・話数・順序）。`task yawa:playlists:sync` が検証済み公開動画をそれらへ追加する。

## 4. 映像・サムネイル・頻度

- **映像**: `scripts/yawa_jizura.py` は pinned JIZURA 0.13.0 で静かな夜の文字映像を作る。元の音声・間・演技と固定キャストの声・関係性を保ち、会話の短い手掛かりを疎に置く。冒頭30秒で具体的な場所・感覚・小さな未解決の気配を示し、会話の転換で色と構図をわずかに温めて静かな回収へつなぎ、その後は余韻を保つ。点滅・跳ね・字幕の連打・説明のための台詞は使わない。
- **レンダー**: Yawa の動画は JIZURA で制作し、別レンダラーや非 JIZURA の代替出力へ切り替えない。キャストの表情差分ポートレートはキャラクター資産として保持し、動画の音声演技と台本の acting 指示を主役にする。
- **サムネイル**: `codex-imagegen` でキャラクターの視覚的な一貫性を保った場面イラストを別に作る。JIZURAの場面から切り出した静止画だけに頼らない。
- **投稿頻度と尺**: 週4本（月・水・金・日 20:30 JST）。毎日の無理な量産を避けて Inauthentic Content 判定を回避し、1本あたり **8〜15分** を目安に総再生時間と満足度を高める。印象的な掛け合い（30〜60秒）は Shorts 展開して新規流入につなげる。
- **声の演技基準**: 会話として自然な近さ、柔らかな明瞭さ、語尾まで届く感情の動きを重視する。長く伸びる吸気・吐息や擦れた息音、耳元への息吹きかけ演出は台本・演技に入れない。

## 5. YouTube 収益化と広告適合ライン（緑アイコン厳守）

- **全年齢・広告適合の徹底**: YouTube の広告適合性ガイドラインに基づき、性的興奮を目的とする描写・喘ぎ・過度な密着ロールプレイを禁止する。
- **メタデータ衛生**: タイトル・説明文・タグに性的連想語（18+系スラング、添い寝・耳舐め等の誤認ワード）を入れない。説明文に「心理学研究」などの形式的な言い訳を載せる手法（旧 ADR-0023 の EDSA 偽装）に頼らず、**作品そのものを健全で魅力的な会話劇・癒やし劇にする**。
- **AI 開示**: 台本・音声・画像が AI 生成である旨を説明文と YouTube の合成メディア設定に明示する。

## 6. 成功指標（YPP・視聴者獲得）

- **収益化マイルストーン**: YouTube パートナープログラム本収益化（登録者1,000人・直近365日の長尺再生4,000時間）と全動画の広告適合（緑アイコン）維持。
- **先行 KPI**: サムネイル CTR、平均視聴時間・完聴率、リピート視聴者数、キャラクター別登録増・高評価率。再生リストはリスト別の開始、視聴時間、保存、話数順の継続を測る。現行の `mart_channel_growth_kpi` はチャンネル単位の集計で、リスト別の実績は未確認として扱う。測定を接続するまではリストの改善効果を断言しない。指標の定義と算出正本は [Star Schema & dbt Standard](../standard/star-schema-standard.md) および `analytics/models/marts/mart_channel_growth_kpi.sql` に置く。
- **データ還流**: `task analytics:refresh` と `task analytics:build` で更新した実績と実聴取の感想を突き合わせ、伸びたキャスト・関係性・ジャンルへ配分を最適化する。
