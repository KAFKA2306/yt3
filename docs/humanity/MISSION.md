# MISSION.md | 雨晴はうの人類観測所

> **雨晴はうの人類観測所が制作する、ジャンルと用途にまっすぐ応えるオリジナル AI 音楽チャンネル。**

- Product: `humanity`
- Version: 2.0
- Updated: 2026-11-20
- Scope: 編集目的、レーベル構造、聴き手への約束、曲名・映像・頻度方針、成果指標。公開許可と正準コマンドは `AGENTS.md`、人格の核は [SOUL.md](SOUL.md) に従う。

## 1. 存在理由とレーベル構造

「雨晴はうの人類観測所」は、特定の架空の町や固定の物語設定に縛られず、曲ごとのコンセプトと聴き手の用途（家事・作業・ドライブ・夜更けなど）に合うオリジナル楽曲とリリックビデオを届ける**オリジナル AI 音楽チャンネル**である。

- **雨晴はうの役割**: 全曲を同じ声で歌う歌手ではなく、**観測所（レーベル）の記録係・キュレーター**として世界を束ねる。
- **歌唱表現**: 曲ごとにテーマ・用途・感情に合わせてボーカル・ジャンル・編曲・音色を自由に設計する。

## 2. 聴き手への約束

- **一曲単体で刺さる体験**: 初聴きでも曲単体でメロディ・歌詞・テンションがまっすぐ届く作品を作る。
- **一曲の強さ＋気分から選べる入口**: 毎日 20:00 JST に異なるコンセプト・ジャンル・用途で1曲制作・公開する。全曲カタログはすべての曲を新着順に収録し、4つの用途別プレイリストは「今どんな時間を過ごしたいか」から曲を見つける入口にする。用途は排他的な分類にせず、曲の主な用途を1つ、別の場面にも明らかに合う場合だけ副用途を1つ付ける。用途が合わない曲は無理に入れず、曲数の均等化もしない。BPMやジャンルは判断材料であり、単独では用途を決めない。定義の正本は `config/music/humanity.yaml` と各曲の `creative_authoring.json`。

| 内部ID | 聴き手が選ぶ場面 | 入口の約束 |
| :--- | :--- | :--- |
| `q1_action_boost` | 家事・運動・ドライブで動き出す | 勢いのあるリズムとフックで、体を動かすきっかけをつくる |
| `q2_focus_boost` | 作業・勉強に集中して続ける | 気持ちを切り替え、一つのことに取り組む時間に寄り添う |
| `q3_daily_flow` | 支度・散歩・移動のペースに乗る | いつもの時間を自分のペースで過ごす曲を見つける |
| `q4_night_reset` | 夜・休憩に気持ちをほどく | 一日の終わりや休憩に、静けさや余韻のある曲を選ぶ |

## 3. パッケージ方針（曲名・概要欄・ビジュアル）

- **曲名**: 3〜15文字前後の**短く口ずさみやすい日本語タイトル**にする（例：`余白のさみしい`、`外れたチェーン`）。ラノベのあらすじ説明のような長文タイトルは禁止し、物語の背景・登場人物・コンセプトは YouTube 概要欄に記載する。
- **ビジュアルとサムネイル**: 映像は JIZURA の拍同期文字PVで制作し、サムネイルは `codex-imagegen` による**曲固有のジャケットイラスト**を標準生成する（JIZURA フレーム抽出だけに頼らない）。
- **Shorts 展開（任意）**: 本編 MV のサビ 30 秒前後を縦型文字PVとして切り出し、再生リスト・本編 MV への新規流入導線にする。

## 4. 技術・権利・開示の原則

- **再現可能な技術品質**: 音声ハッシュ一致、途切れなし、48kHz ステレオ、映像と音声の長さ一致、YuE2 モデルライセンス（個人クリエイター収益化条項）の記録を維持する（`music_integrity` / `music_provenance` / `visual_provenance` / `music_rights`）。
- **権利と透明性**: 歌詞は毎曲新規生成し、第三者の歌詞・音源を使わない。AI 生成開示と YouTube の合成メディア設定（`containsSyntheticMedia: true`）を常に付与する。
- オーナー指示（2026-11-08）に従い、旧リリースゲート（ADR 0045）および [旧編集監査基準書](../standard/humanity-observatory-audit-standard.md) の CQO 承認ゲートは廃止済み。品質・権利・表現の責任は制作工程が担う。

## 5. 成功指標（YPP・視聴者獲得）

- **収益化マイルストーン**: YouTube パートナープログラム本収益化（登録者1,000人・直近365日の長尺再生4,000時間、または Shorts 1,000万再生）と Inauthentic Content 判定の回避。
- **先行 KPI**: サムネイル CTR、楽曲完聴率、高評価率、再生リスト経由の連続視聴・リピート率、1曲あたり登録増。指標の定義と算出正本は [Star Schema & dbt Standard](../standard/star-schema-standard.md) および `analytics/models/marts/mart_channel_growth_kpi.sql` に置く。
- **データ還流**: `task analytics:refresh` と `task analytics:build` で更新した YouTube Analytics と聴取評価（ledger rating）を突き合わせ、聴き手に刺さった曲調・関係性・ビジュアルへ注力する。プレイリストの成長はリスト単位の開始・再生・視聴時間・保存で見る。現行 `mart_channel_growth_kpi` のプレイリスト比率はチャンネル単位であり、4リストの優劣は判定できない。プレイリスト単位の実績は未取得として扱い、測定開始前に改善を断言しない。
