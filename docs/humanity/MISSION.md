# MISSION.md | 雨晴はうの人類観測所

> **日々の不器用さを、曲で愛おしむ。いつでもかけ流せる場所を育てる。**

- Product: `humanity`
- Version: 0.1
- Established: 2026-10-25
- Scope: 編集目的、聴き手への約束、曲調の選び方、止める線。公開許可や実行手順ではない。人格は `SOUL.md` に従う。

## 1. 存在理由

人類の不器用さを愛おしむ曲と映像を、AI で作り、公開する。聴き手がプレイリストをいつも流せる状態を目指す。

## 2. 聴き手への約束

- **増え続ける**: プレイリストが約 2 時間になるまでは、早めに増やす。到達後は頻度を下げる。目標値と頻度は `config/music/humanity.yaml` が持つ。
- **毎回新しい**: 音調、旋律、シンセの音色が曲ごとに違い、驚きがある。
- **品質を保つ**: 音と声の質を落とさない。増産のために緩めない。

## 3. 曲調の選び方

- 曲調は config の軸（ジャンル系統、テンポ帯、調、シンセの質感、ボーカル加工）から選ぶ。固定の型を置かない。
- どれが心地いいかは、聴いた評価（ledger の rating）で絞る。公式に定まったテンポ帯や分類は見つかっていないため、決め打ちしない。
- 好きな作品は、アーティスト名や曲名ではなく、質感や構造の特徴に分解して使う。

## 4. 止める線

公開を止めるのは次の 4 つだけにする。

- 再生できる成果物である: 音声のハッシュが ledger と一致し、途切れておらず、動画と音声の長さが合う（`music_integrity`）。曲の長さの下限や末尾の音量では止めない。
- 出どころの記録がある（`music_provenance`、`visual_provenance`）。
- 権利（歌詞は新規生成で、第三者の歌詞と音源を使わない）（`music_rights`）。
- 公開ゲートが PASS している。

AI 生成の開示は常に入れる。連絡先は外部、動画、リポジトリに入れない。それ以外の質の評価は、止める条件にしない。

## 5. 成功指標

- 聴き返しと、プレイリストの視聴時間。
- 曲調の分布の偏りを定期的に点検する。説明できない偏りは直す。
- 未公開を成功に数えない。公開は遠隔の read-back で確認する。

## 6. 責務分離

- `AGENTS.md`: 正準コマンド、公開の条件、権限。
- `config/music/humanity.yaml`: 頻度、目標、曲調の軸、検査のしきい値。
- `docs/adr/0045-humanity-music-video-release-gate.md`: 公開ゲートの決定。

本書は新しい公開許可を意味しない。実行は正準の Taskfile 経路とゲートに従う。
