# 人類観測所の作詞と物語づくり

## レーベルとしての位置づけ

「雨晴はうの人類観測所」は、雨晴はうが「晴れ待ち坂」の6人の日常と転機を観測し、曲として記録する物語音楽レーベル。雨晴はうは全曲を歌う単一ボーカルではなく記録係・ナビゲーターであり、各曲は主人公や感情に合う声質・音色で歌う。方針の正本は [MISSION.md](MISSION.md)、人格の核は [SOUL.md](SOUL.md)。

## 聴き手に届けるもの

毎曲に、ひとことで伝わるコンセプトと、人物の関係が動く出来事を作る。共有世界の正本は [story-world.json](story-world.json)。一曲だけ聴いても状況と感情が分かり、続けて聴くほど関係の変化や伏線に気づける設計にする。

HoneyWorks の初聴きで追える関係性とストーリー性、DECO*27 の世界観と言葉の結び付き、IMOJIST の曲調と音作りを好みの参考にする。歌詞、人物、筋書き、旋律、固有フレーズは借りず、晴れ待ち坂オリジナルの表現にする。

## 曲名と概要欄（クリックと記憶の設計）

- **曲名**: **3〜15文字前後の短く記憶に残る曲名**にする。出来事のあらすじや登場人物の説明を曲名に詰め込まない。
- **概要欄**: 曲のコンセプト（1文）、出来事と人物関係（2〜3文）、登場人物、歌詞全文、AI開示とクレジットを掲載し、聴き手が曲名の意味と物語世界を概要欄で味わえるようにする。
- **頻度と消費ペース**: 週3曲ペースで丁寧に届ける。一曲で人物関係の大きな結論を一気に消費し尽くさず、小さな気づきや距離の変化を積み重ねる。

## Neon の制作

Neon が曲名、曲のコンセプト、登場人物、物語、人物関係、音楽方向（英語 style）、歌詞、JIZURA 演出計画、ジャケットサムネイル用プロンプトを一貫して設計する。完成稿の前にタイトルだけを批評し、完成稿の後にその批評と物語・歌詞を照合して短く強い曲名へ磨き上げる。

## JIZURA 映像とジャケットサムネイル

- **本編映像**: JIZURA による拍同期・歌詞同期の文字PV。曲の感情に合うテーマ（`lyricpv` / `kinetic` / `wa` / `horror` / `pop` / `ballad`）とアクセント配色3色を選び、生成プロジェクト JSON を保存する。
- **サムネイル**: JIZURA フレーム切り出しに頼らず、`codex-imagegen` で曲の情景と登場人物の空気を描く**「晴れ待ち坂」統一タッチのジャケットイラスト（文字なし）**を生成する。

## 聴取と改善

歌詞、歌声、旋律、JIZURA、サムネイル、公開後の YouTube Analytics（CTR・完聴率・高評価率・再生リスト回遊）を合わせて確認し、次の曲の方向を磨く。点数や固定チェックリストで自動却下しない。
