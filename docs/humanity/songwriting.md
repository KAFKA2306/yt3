# 人類観測所の作詞と物語づくり

## 1. 完了場面と現行の障害（`reconceptualize` 2026-11-21）

- **完了場面**: 初見のリスナーが再生から最初の 1 サビまでに「このフレーズと視点が刺さる・口ずさめる」と感じて完聴・リピートし、2 曲目を聴いても「別の感情と音なのに同じ町の別の顔だ」と気づける楽曲を毎回届ける。
- **実測された最大の障害**: 過去 156 曲の語彙分布（`task lexicon:report -- humanity`）で **`少し` 64%・`静か` 53%・`そっと` 37%・`不器用` 34%・`まま` 32%** と微温語へ極端に偏り、直近曲でも「余白・答えを急がない・決めない」に着地する**説明的な散文エッセイ歌詞**へ収束していた。

## 2. 作詞の 4 つの転換（歌として刺す設計）

1. **散文の説明ではなく「口ずさめるフック（音の快感）」を核にする**
   - サビ頭またはサビ終わりに、**10 文字前後で声に出したくなるキラーフレーズ（フック）**を必ず 1 つ置く。
   - 説明的な接続（〜はずで、〜けれど、〜みたいに）や抽象語の重ね掛け（余白・答え・名前・時間）を削り、**動詞・短い台詞・擬音・体言止め・韻・反復**でリズムと推進力を作る。
2. **「微温エモ」一辺倒をやめ、曲ごとに感情モードを振り切る**
   - 毎曲、明確に異なる感情・視点モードを選ぶ（例：**疾走・衝動** / **毒気・皮肉・強がり** / **軽快コメディ・掛け合い** / **切実な後悔・すれ違い** / **夜中の独白** / **背中を押す爆発**）。
   - 「答えを急がない」「決めないままでいい」系の着地を連続させない。弱め語（`少し`・`静か`・`そっと`・`不器用`・`余白`）を無意識の口癖として使わない。
3. **舞台チェックリストを捨て「一点突破の具体物」で世界を立てる**
   - 固定の定番舞台や小道具をチェックリストのように並べるのを禁止し、曲のテーマ・用途に直結する具体物だけを置く。
   - 1 曲に持ち込む舞台要素は **0〜1 個** に絞り、代わりにその曲だけの固有の具体物・仕草・音（例：自販機の釣り銭、折れたシャー芯、既読のつかない画面、油まみれの軍手）から物語を立ち上げる。
4. **YuE2 の歌唱に乗る行長・セクション設計**
   - `[verse]` / `[pre-chorus]` / `[chorus]` / `[bridge]` で**1 行のモーラ数と息継ぎ**を意識的に変える（例：短く刻む A メロ → 語尾を伸ばして開くサビ）。長すぎる散文行を詰め込まない。

## 3. レーベル構造・曲名・概要欄・ビジュアル

- **レーベル位置づけ**: 雨晴はうは全曲を歌う単一ボーカルではなく観測所の記録係・ナビゲーター。各曲は主人公や感情に合う声質・音色で歌う（方針: [MISSION.md](MISSION.md)、核: [SOUL.md](SOUL.md)）。
- **好みの参照軸**: HoneyWorks の関係性と劇的な感情の振り幅、DECO*27 の言葉遊び・毒気・中毒性、IMOJIST の音作りを好みの方向性とする（既存作品の歌詞・人物・筋書き・旋律・固有表現は一切借りない）。
- **曲名**: **3〜15 文字前後の短く記憶に残る曲名**。あらすじ説明は入れず、物語の前提・登場人物・背景は **YouTube 概要欄** に載せる。
- **映像とサムネイル**: 本編は pinned JIZURA 0.13.0 の曲固有 PV とする。各プランに歌い出し、30秒以内の歌詞手掛かり、曲固有モチーフ、ブリッジまたは最後のサビでの変化、変化後の配色を記録し、実音源から整列した歌詞の上で同じモチーフを回収して新しい状態を終わりまで保つ。テーマ・スタイル・ムード・seed・palette は曲ごとに選び、別レンダラーや非 JIZURA 出力へ切り替えない。サムネイルは `codex-imagegen` による**曲の世界観に合う固有ジャケット（文字なし）**を生成する。
