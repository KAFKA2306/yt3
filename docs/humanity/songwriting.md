# 人類観測所の歌詞・世界観設計

## 方針

人類観測所が人に向ける温かな関心を持ち、歌ごとに固有の世界、歌詞、音楽を作る。ユーザーが好んだ「ラブパラ」の世界観・歌詞づくりは創作上の参考として扱い、特定の作品の歌詞、言い回し、人物、筋書き、見せ方を引き継がない。

主題、人物、関係、視点、世界の仕掛け、感情、言葉づかい、節構成、尺、反復の有無は固定しない。恋愛、言葉遊び、意味の飛躍、比喩、特定の物語構成を毎回の条件にしない。人間への関心はレーベルの軸だが、「不器用さ」を毎曲の題材にする必要はない。

ユーザーは [IMOJIST のチャンネル](https://www.youtube.com/@IMOJIST)の曲調と音作りを好む。この好みを音楽設計の参考情報として渡し、ジャンルや特定曲の再現条件にはしない。歌ごとに合う方向を選び、旋律や固有のフレーズ、アレンジを写さない。

## 参考資料から分かったこと

DECO*27さんはインタビューで、会話の中で耳に残った言葉からイメージと世界観を広げること、人物や関係にある感情を選んで曲の世界を作ること、気持ちを直接言わず意外な語の組み合わせで伝えることを話している。[STREAMのインタビュー](https://strmweb.jp/archives/16462/2/)

ユーザーが示した「ラブパラ」について、公式のOTOIRO告知はユーロビートとパラパラを組み合わせた求愛曲として紹介している。[OTOIRO公式告知](https://otoiro.co.jp/topics/114767/) この作品から取り入れるのは、曲の核・言葉・音・視覚世界を一体として設計する着眼点である。具体的な語彙やフレーズは使わない。

これらは創作の手掛かりであり、毎回適用する公式ではない。会話の一言、言葉の響き、関係の変化、物の見え方、音楽の質感など、発想の入口は曲ごとに選ぶ。世界を作るのに役立つ言葉遊び、意外性、反復、韻、感情とサウンドの対比は使ってよいが、合わないときは加えない。

## 歌詞を作る

歌の核を見つけ、その歌だけの人物・関係・場面・象徴・感情の動きを組み立てる。これらを全部そろえる必要はない。言葉の意味と音を音楽設計に合わせ、歌ったときの自然さ、耳に残る箇所、聴き手が世界へ入れる魅力を整える。感情は直接表現しても、景色や行動に預けてもよい。

歌詞は自由な行分けで生成する。固定の章数、行数、話者、時間幅、視点、題材、フック、韻、感情、ウェブトレンド検索、過去曲の題材・語彙を避ける規則は置かない。過去作品の記録を創作の禁止リストとして使わない。歌詞は新作として書き、他者の歌詞や固有表現は流用しない。

## 評価と現行制作経路

歌詞と曲を合わせて聴き、言葉の運び、情景・関係の伝わり方、印象に残る箇所、音楽との一体感を見直す。点数を合否条件にせず、聴取所見から直す箇所を探す。

現在のYuE2経路は歌詞と曲を同時に生成する。既存曲の旋律を保ったまま歌詞だけ改稿する比較はできないため、同一旋律で検証したと報告しない。

生成コードはタイトル、音楽生成用の補足、自由形式の歌詞を受け渡す。歌詞の形式や場面を独立した必須フィールドにしない。YAMLには作品方針を置かず、音楽生成に必要な実行設定を管理する。
