# 人類観測所の作詞と物語づくり

## 聴き手に届けるもの

毎曲に、ひとことで伝わるコンセプトと、人物の関係が動く出来事を作る。HoneyWorksに感じる初聴きで追える関係性とストーリー性を好みの方向として扱う。作品ごとに人物や物語を作り直すのではなく、共有世界の人物と関係を曲の中で育てる。一曲だけ聴いても状況と感情が分かるようにする。

共有世界の正本は `story-world.json`。各曲はそこにある人物や関係を使い、過去曲の展開も必要に応じて参照する。恋愛、青春、日常、コメディなどの題材や曲構成は固定しない。世界のつながりを保ちながら、曲ごとの核と音楽を変える。

DECO*27に感じる世界観と言葉の結び付き、IMOJISTの曲調と音作りも好みの参考にする。歌詞、人物、筋書き、旋律、固有フレーズは借りず、人類観測所の表現に作り直す。

## Neonの制作

Neonが世界の設定、曲名、曲のコンセプト、人物関係、出来事、感情の変化、音楽方向、歌詞を設計する。完成稿の前にタイトルだけを批評し、完成稿の後にその批評を物語と照合して改題する。決まった章数、行数、視点、展開、韻、フックは置かない。

## JIZURAの映像

JIZURAは物語を説明するキャラクターアニメーターではなく、歌詞の時刻、文字の配置、動き、色調を音楽に合わせる文字PVとして使う。JIZURA自身の音声解析で拍を検出し、Neonが曲の物語と音に合うテーマとアクセント配色を選ぶ。反復する言葉を映像でも結び付けたい曲では「統一感」、歌詞を追いやすくしたい曲では「文字整列」を使う。曲の核に沿う文字演出を選び、人物の場面描写を行うツールとしては扱わない。

歌詞の表示時刻は完成音声から取り、JIZURAの選択結果を含むプロジェクトJSONを保存する。JIZURAが実際に扱えるテーマ、書体、動きに合わせ、人物の表情や場面そのものを動画が描いたとは説明しない。

## 聴取

歌詞、歌声、旋律、JIZURAを合わせて聴き、コンセプトと人物関係が伝わる箇所、物語の変化、印象に残る言葉、映像との結び付きを確かめる。所見から直す価値のある箇所を選ぶ。点数や固定チェックリストを合否に使わない。
