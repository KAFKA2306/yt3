# 📊 プラットフォーム・レテンション・マシン：技術仕様書 (PRM Spec v1) 🛠️

あーしら「秒算マネー」の動画が、アルゴリズムという戦場で生き残るための「硬い」仕様だよっ！💕
抽象的な「面白さ」を排除して、機械的に検証可能なメトリクス（指標）だけで構成してるから、しっかり守ってね✨

## 1. 🎣 フック・ループ (Hook Loop)
**定義**: 視聴者のアテンション（注意）を強制的に再起動させるための循環構造だよ✨
- **メトリクス**: `novelty_event_interval` <= 35sec
- **FAIL条件**: 35秒以上、新しい具体的事実・意外な展開・数値的な驚き（Novelty Event）が提示されない場合。
- **検証項目**: 
  - `surprise_event_count`: セクションあたりの期待裏切り回数
  - `unresolved_claim_density`: 常に1つ以上の「未解決の主張」を保持していること。

## 2. 🌀 オープンループの永続化 (Open Loop Persistence)
**定義**: 脳の「未完結を嫌う性質」を利用した、離脱防止の緊張状態だよっ！
- **メトリクス**: `unresolved_question_count` >= 1 (常に維持)
- **FAIL条件**: 直線的な説明（事実 ➡️ 理由 ➡️ 終了）で、すべての疑問が回収されてしまう「完結状態」が10秒以上続く場合。
- **検証項目**: `loop_resolution_delay` (疑問提示から完全解決までの秒数)

## 3. 🎢 感情のオシレーション (Emotional Oscillation)
**定義**: 平坦なリズムを破壊するための、感情の極性変化だよ✨
- **メトリクス**: `emotional_polarity_shift` >= 1回 / 45sec
- **FAIL条件**: 45秒以上、同一の感情トーン（例：ずっと賢い解説、ずっと不安な煽り）が継続する場合。
- **検証項目**: `amplitude_variance` (感情の振幅の分散値)

## 4. 🚀 共有トリガー (Share Trigger)
**定義**: 視聴者の「社会的地位」や「帰属意識」を向上させるための情報設計だよ💕
- **検証項目**: 以下のいずれか1つ以上を明示的に含むこと
  - **Status Gain**: 「インサイダーしか知らない一次情報」
  - **Future Advantage**: 「他人が気づく前に動ける具体的な先行利益」
  - **Fear**: 「今すぐ共有しないと手遅れになる危機シグナル」

## 5. ⚡ パターン・インタラプト (Pattern Interrupt)
**定義**: 慣れによる脳の「スリープモード」を解除する強制介入だよっ！
- **メトリクス**: `rhetorical_cadence_limit` <= 50sec
- **FAIL条件**: 同じ話し方、同じ文構造、同じBGMのテンポが50秒以上続く場合。
- **検証項目**: `interrupt_event` (沈黙、極端な例え、数字の急激な強調など)

## 6. 🔢 情報密度 (Informational Entropy)
**定義**: 「抽象的な filler（無駄話）」を排除し、事実の密度を担保するよ✨
- **メトリクス**:
  - `abstract_noun_ratio` < 15%
  - `entity_density` >= 5個 / 1000文字 (固有名詞、具体的数値)
- **FAIL条件**: 抽象名詞の比率が15%を超える、または具体的エンティティが不足している場合。

## 🛡️ ASVS・証拠の階層 (No Evidence, No PASS)
あーし（AuditAgent）は、以下の「硬い証拠」がない企画は、どんなに内容が良くてもボツにするよっ！🙅‍♀️

- **Tier 0 (物理証拠)**: ASR（音声認識）による数字の1:1一致。
- **Tier 1 (セマンティック証拠)**: サムネ単語のイントロ5秒以内での完全一致。
- **Tier 2 (構造証拠)**: 上記メトリクスの閾値クリアログ。

「最強」とか「革命」とか言わずに、この数字を黙って達成してねっ！ふぁいとー！💕
