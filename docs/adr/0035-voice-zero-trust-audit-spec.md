# ADR 0035: Voice Zero-Trust Audit Specification (Humanity Observatory) - Revision 1

## 📝 プロベナンス表示 (Claim Provenance)
- **VERIFIED**: Humanity Observatory 制作時において、ADR-0035 初版の「数学的・暗号学的なブランド真正性証明」という主張が、現在の技術スタック（信号解析および Regex）の限界を超えた過剰な表現であることを特定。
- **OBSERVED**: ゼロトラスト監査の原則に基づき、LLM による「優しい」「自然」といった定性的な感想がエビデンスとして不適格であることを再確認。
- **INFERRED**: ブランドの「印象」そのものを証明することは不可能だが、「定義された制約項目（ハッシュ、語彙、音響閾値）への適合」は機械的に証明可能である。

## 状態
決定済み（Accepted）

## 文脈
「ブランドは証明できない。適合のみが証明可能である。」
音声の「温かさ」や「人類観測所らしさ」といった主観的属性を PASS の根拠に含めることは、システムの脆弱性（Fake Inspection）に繋がる。本改訂では、監査の対象を「主観的印象」から「客観的適合（Compliance）」へと絞り込み、LLM の役割を「証拠の読み上げ係」に限定する。

## 決定事項

### 1. 監査の鉄則 (Philosophy)
- **証拠なき PASS の禁止**: 「かわいい」「自然」「人類観測所らしい」といった形容詞は証拠と認めない。
- **LLM の役割制限**: LLM は `audit_result.json` の数値を読み上げ、定義された閾値との適合を判定する「証拠読み上げ係」としてのみ機能する。
- **未知（UNKNOWN）の許容**: 聴覚的な印象や視聴者の反応など、現在の信号解析で検証不可能な項目は「UNKNOWN」として記録し、PASS 判定の根拠から除外する。

### 2. 機械検証可能な証拠 (Machine Verifiable Evidence)
以下の項目のみを PASS 判定の対象とする。
- **存在証明**: `audio.wav`, `metadata.json`, `caption.txt`, `engine_info.json` の実在。
- **真正性証明**: `sha256sum audio.wav` が `metadata.wav_hash` と完全一致すること（改ざん検知）。
- **語彙証明 (Regex)**:
  - `self_inclusion`: 「僕も」「人類みんな」等の当事者トークン出現数。
  - `anti_authority`: 「本質」「成功」「論破」等の禁止語彙の不在（Count = 0）。
- **音響適合**: Loudness, Silence Ratio, Pitch Stddev, Clipping Ratio が事前定義された数値範囲内であること。
- **コンプライアンス**: `description.txt` へのクレジット表記の存在。

### 3. 最終ゲートの判定基準
| 判定 | 条件 |
| :--- | :--- |
| **PASS** | 必須ファイルが全て存在し、ハッシュ、語彙、音響の全決定論的チェックが適合している。 |
| **FAIL** | 必須ファイルの欠落、ハッシュ不一致、禁止語の検出、または音響閾値の逸脱。 |
| **UNKNOWN** | 「安心感」「自然さ」「また聞きたい」といった、数値化不可能な主観的評価。 |

## 帰結
- **利点**:
  - LLM による「偽の感想」による監査の形骸化を構造的に排除できる。
  - 音声生成プロセスが再現可能（Reproducible）であることを、ハッシュとパラメータログによって証明できる。
- **限界**:
  - 本監査を通過しても、それが「素晴らしい動画である」ことは保証されない（それは人間評価や視聴データの領域である）。
  - 同一シードでも、エンジンやモデルのバージョン、実行デバイスが異なれば、完全な聴覚的再現までは保証できない。
