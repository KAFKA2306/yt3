# ADR-0017: 物理的文字数（5000文字超）による台本管理への移行

## Status

Accepted

## Context

これまでの台本生成では「10分」「30分」といった時間軸での思考に依存していたため、描写の密度が安定せず、実際には数分で終わってしまう文字数不足（1000〜2000文字程度）が頻発していた。ASMRコンテンツとしての没入感を担保するには、曖昧な時間管理ではなく、物理的な「文字数」を絶対的な制約とする必要がある。

## Decision

「10分」「30分」といった曖昧な時間軸での思考を完全にパージし、**「最低5000文字」という物理的な文字数制約**を全レイヤーで義務化する。

1.  **スキーマの置換**: `ContentOutlineSchema` から `estimated_duration`（推定秒数）を削除し、`target_character_count`（目標文字数）に置き換える。
2.  **プロンプトの再定義**: LLMへの指示から「尺」や「分」という言葉を排除し、具体的な「文字数」と「詳細な情景描写」のみを要求する。
3.  **強制執行ハーネスの導入**: 初期生成で文字数が不足した場合、5000文字を超えるまで自動的に拡張（Expand）し続ける執筆ハーネス `asmr:expand` を標準ワークフローに組み込む。

## Consequences

- AIが「時間」で妥協することを防ぎ、常に高密度な描写（衣擦れ、呼吸、細かな環境音の書き込み）を強制できるようになった。
- 1,000文字程度の初期台本を、描写の密度だけで10,000文字超まで自動拡張させる実績を確認。
- 「30分用の台本を書いて」という曖昧な要求が死滅し、物理的なボリュウムに基づく決定論的な制作が可能になった。
