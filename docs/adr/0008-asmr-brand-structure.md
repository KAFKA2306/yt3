# ADR-0008: ASMRブランド「夜話アーカイブ」の世界観と命名構造

## Status

Accepted

## Context

単発のシチュエーション消費に留まらず、100作品以上の蓄積を前提とする ASMR ブランドでは、作品ごとの独立性と全体の一貫性を同時に維持する必要がある。

KAFKA の活動理念である観測、アーカイブ、孤独と安心の同居を ASMR に実装するため、ブランド、施設、作品の関係を整理した命名構造が必要だった。

## Decision

チャンネルブランドを `夜話アーカイブ ASMR` と定義し、以下の構造を採用する。

1. 世界観を施設として扱う
   - 各シリーズを単なる再生リストではなく、アーカイブ内に存在する訪問可能な施設として設計する。
   - これにより、視聴者が「戻れる場所」として認識しやすくなる。
2. 命名を 3 層で分ける
   - Brand: `夜話アーカイブ ASMR`
   - Facility Series: `月灯旅館`、`宵闇ラウンジ`、`雨音避難所` など
   - Production Record: 各シリーズ内の具体的な動画タイトル
3. 名前の役割を固定する
   - ブランド名は全体の総称として使う。
   - 施設名はシリーズの空気感と関係性を担う。
   - 動画タイトルは個別の観測ログとして機能させる。

## Naming Principles

1. 情景想起を優先する
   - 名前だけで場所、時間、空気感、関係性が補完される設計にする。
2. 語彙の一貫性を保つ
   - `Archive`、`Log`、`Observation` などの語彙を含め、静かな未来感を統一する。
3. 建築的メタファーを使う
   - シリーズ名には `旅館`、`ラウンジ`、`診療室` などの施設性を持つ語を含める。

## Consequences

- 長期シリーズでもブランドの核が揺らぎにくくなる。
- 音声作品、配信、翻訳展開などへ拡張しやすくなる。
- 視聴者がシリーズを「場所」として記憶しやすくなる。
- 一方で、チャンネル名が抽象的になるため、サムネイルや動画タイトルでは `ASMR` などの直接的なキーワードを補う必要がある。
