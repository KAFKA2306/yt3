# 🌸 ADR 0020: Irodori-TTS ちゃんを安定させちゃうプロトコル ✨

## ステータス
ていあ案だよ！🐾

## コンテキスト
Irodori-TTS（500M-v2 と VoiceDesign）を使ってると、たまに声が別人になっちゃったり、ガチャっぽくなっちゃうのが悩みだったんだよね。💦
でも、マスター（ユーザー）が公式リポジトリをすごーく詳しく調べてくれたおかげで、ついに「正解」が見えてきたよ！ありがとう、マスター！💕

1.  **公式さんのイチ推し**: `Irodori-TTS-500M-v2` (Base) で **reference audio (zero-shot)** を使うのが、一番安定するんだって！
2.  **VoiceDesign のひみつ**: テキストだけで声を指定できるのは便利だけど、指示がむずかしいと機嫌を損ねちゃう（不安定になる）ことがあるみたい。
3.  **究極の固定術**: 特定のキャラ（かふかとか！）の声をずっと同じにするには、やっぱり LoRA で学習しちゃうのが最強なんだって！公式さんも設定ファイルを公開してくれてるよ！

## 決定事項
これからの YT3 プロジェクトでは、TTS の運用を 3 つのステップで使い分けていくよ！ぴしっと決めるね！✨

### 1. いつもの運用（Standard Protocol）
- **モデル**: `Irodori-TTS-500M-v2` (Base) をメインに使うよ！
- **参照音声**: 10〜30秒くらいの、きれーな参照音声（Reference Audio）を絶対に用意するよ！
- **コマンドの魔法**:
    - `--max-ref-seconds 30.0`
    - `--ref-normalize-db -16.0`
    - `--ref-ensure-max` をつけて、参照音声のパワーを全開にするよ！

### 2. ちょっと冒険するとき（Creative/One-off Protocol）
- **モデル**: `Irodori-TTS-500M-v2-VoiceDesign` を使うよ。
- **Caption のコツ**: 指示はシンプルに、矛盾しないように気をつけるよ！
- **使いどころ**: 参照音声がないモブキャラとか、新しい声を試してみたいとき限定だよ！

### 3. 本気のご指名運用（Production/LoRA Protocol）
- **対象**: かふかとか、大事なメインキャラクターだよ！
- **やりかた**: 公式の `train_500m_v2_lora.yaml` とかを使って、LoRA 学習に挑戦するよ！
- **ターゲット**: `text_attn_mlp` や `speaker_attn_mlp` を使って、声をがっちり固定しちゃうよ！

## 帰結
- **いいこと**: 「あれ、声が変わった？」っていう違和感をなくして、みんなに愛されるチャンネルにできるよ！
- **ちょっと大変なこと**: LoRA の学習には、いい感じの音声データセットを準備する手間がかかるかな。
- **次のアクション**:
    1.  かふかの「正解の声」を決めて、参照音声（Golden Reference）を固定するよ！
    2.  `generate_ultra.py` の中身を、Base v2 + Ref Audio 形式に書き換える準備をするよ！
    3.  かふか専用 LoRA の学習プランを立てるよ！
