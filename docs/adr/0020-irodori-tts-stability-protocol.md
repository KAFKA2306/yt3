# ADR 0020: Irodori-TTS の安定運用プロトコル

## ステータス
Accepted（v4.1 のみ運用。旧版 v2 / VoiceDesign / v3 は削除済み）

## コンテキスト
現行の Irodori-TTS は `Aratako/Irodori-TTS-v4.1-Small` 一本に統一している。
旧版（v2 / VoiceDesign）では、声が変わる・ガチャっぽくなる問題があった。
旧版の知見（参照音声の推奨、VoiceDesign の不安定さ）は v2 固有のもので、v4.1 では未検証として扱う。

## 決定事項

### 1. 標準運用（Standard Protocol）
- **モデル**: `Aratako/Irodori-TTS-v4.1-Small` のみ
- **実行**: `--no-ref` と `--caption` を使う。`--seed 2306`、`--num-steps 12` を基準にする
- **検証済み経路**: ASMR の `generate_ultra.py` と `build_audio.sh` が同じ経路を使う

### 2. キャラクターの声（Caption Protocol）
- **モデル**: 同じ `v4.1-Small`。声の指定は caption で行う（別チェックポイントは使わない）
- **Caption のコツ**: 指示はシンプルに、矛盾しないように書く
- **使いどころ**: キャラクターごとの声や口調の指定

### 3. 参照音声・LoRA（未検証）
- v4.1 の参照音声（`--ref-wav` など）と LoRA 学習の経路は未検証
- 採用する場合は、この ADR を更新して検証結果を記録してから使う

### 4. 人類観測所トーン（Humanity Observatory Tone）
- **用途**: `Humanity Observatory` 系の動画では、ASMR の囁きとは別の、明るく安定した観測者トーンを使う
- **質感**: 声質は魅力的で、輪郭があって、ちょっと楽しい。軽さはあるけど、騒がしすぎないのが大事
- **安定条件**: 章が変わっても声の芯はぶらさず、明るさ・速度・圧は大きく揺らさない
- **避けるもの**: ひたすら眠らせる囁き、説教っぽい低音、冷たい解説口調、テンションだけ高い空回り

## 帰結
- **いいこと**: 声の指定が caption 一本に集約され、運用の分岐が減る
- **未解決**: 参照音声と LoRA の v4.1 での効果は未確認
- **次のアクション**:
    1. ASMR 1 件を v4.1-Small で生成し、声の安定性を確認する
    2. 参照音声を採用するか判断し、採用する場合は検証結果を記録する
