# ADR-0009: Visual Design Strategy: Kafka Presence

この文書は、Kafka Core のビジュアル基準に加えて、AI っぽさを消す生成指針もまとめる。

All visual assets must adhere to the "Kafka Core" visual identity to maintain brand consistency across different situations (Onsen, Echo, etc.).

## Base Identity
Maintain the following traits regardless of setting:
- **Hair**: Light-blue with lavender ends.
- **Eyes**: Blue-purple, slightly tired.
- **Vibe**: Emotional futurism, observational loneliness.

## Application Example: Echo Memory Rental
[OUTFIT]: oversized dark navy hoodie, worn fabric texture
[BACKGROUND]: small rainy apartment room with city lights outside
[LIGHTING]: soft blue monitor glow, dim night lighting
[MOOD]: quiet late-night loneliness

## Application Example: Moonlight Inn (Onsen)
[OUTFIT]: light gray yukata, slightly disheveled
[BACKGROUND]: dimly lit traditional tatami room, snowy garden visible through the window
[LIGHTING]: warm candle light, blue moonlit snow reflection
[MOOD]: intimate healing, fragile warmth

## Anti-AI Aesthetic Rules

この節は、以前別ファイルで管理していた脱・AI生成感のチェックリストを統合したもの。

- 肌や服は `matte finish` と `visible fabric weave` を優先する
- `subtle asymmetry`、`slight head tilt`、`uneven hair strands` で左右対称すぎる印象を避ける
- `natural eye reflection` と `understated iris detail` で瞳の過剰装飾を抑える
- `dramatic environmental lighting` と `occlusion shadows` で物理的な光を守る
- `lived-in room`、`practical clutter`、`mixed lighting temperatures` で生活の痕跡を残す
- `foreground obstruction`、`slightly missed focus`、`edge blur` で観測された瞬間の不完全さを入れる
- `masterpiece`、`best quality`、`8k` などの AI 高級語は使わない
- 手や指の破綻が出る構図は避け、必要なら映さない
