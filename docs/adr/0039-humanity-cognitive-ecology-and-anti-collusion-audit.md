# 🌸 ADR-0039: 人類観測所・認知生態系＆反コリュージョン監査規格 (Cognitive Ecology & Anti-Collusion) 🌸

## 🎀 1. 背景と課題 (Context & Critical Problem)

2026-05-20のプロダクション実行において、非常に深遠な「AI品質監査の落とし穴」が観測されましたっ！
品質監査エンジン（Auditor）の精度を高めるために、「具体的な例（コンビニ、洗濯物、イヤホン、アイスクリーム等）」や「演出の固定指示（夏の夕方）」を監査基準に含めると、生成エンジン（Generator）が**「監査をパスするためだけに、その単語をそのまま台本にコピペしてカンニング（Collusion）し始める」**という現象です。

これは**『プロンプト汚染（Example Contamination）』**または**『監査による文化支配』**と呼ぶべきバグであり、放置すると人類観測所の動画が毎回「夏の夕暮れにコンビニでアイスを買って、イヤホンが絡まる」という極めて狭い定型パターン（パターンの死滅・崩壊）に陥ってしまいます。

人類観測所が本来観測すべきなのは、固定された記号（アイスや夕焼け）ではなく、**「日々変化するリアルな生活の温度（Mundane Temperature）」**です。この認知多様性と決定論的整合性を両立するため、本ADRにて次世代の監査規格を定義しますっ！(⑅•衣•⑅)✨

## 💡 2. 意思決定とアーキテクチャ方針 (Decision & Architecture)

### 2.1. 監査例文の完全抽象化（Object Ontology の導入）
監査および生成のプロンプトから「特定の名詞（アイス、イヤホン等）」を完全に排除し、抽象度の高い「生活温度オブジェクト（Mundane Ontology）」として監査します。

*   ❌ **禁止**: 「アイスがあるか？」をチェックする。
*   ⭕ **推奨**: 「湯気、レシート、充電、エコバッグ、ぬるいお茶、半分閉じたカーテン」など、**『物理世界に錨（Anchor）を下ろした、生活の息遣いを持つ具体物』**が3つ以上検出されているかを監査する。

### 2.2. コリュージョン汚染監査 (`example_contamination_risk` / `PROMPT-COLLUSION-001`)
監査・生成プロンプトの中に書かれている「例文」や「指示語」が、生成された台本の中にどれだけ「そのまま漏洩・再利用されているか」を静的解析で監視します。

*   **コリュージョン警告トリガー (PROMPT-COLLUSION-001)**:
    台本内にプロンプト由来のサンプル名詞が一定回数（例：3回以上）重複して検出された場合、直ちに監査失敗（FAIL）または警告を出力する。

### 2.3. 人類エントロピーの最大化 (`humanity_entropy` KPI)
長期運用時に台本が「人類観測所っぽいお決まりのテンプレ」に崩壊するのを防ぐため、以下の5つの次元でエントロピー（多様性）を測定し、KPIとしてトラッキングします。

$$\text{Humanity Entropy} = H(\text{Time}) + H(\text{Weather}) + H(\text{Room}) + H(\text{Object}) + H(\text{Emotion})$$

*   **時刻多様性 (Time-of-day Diversity)**: 朝7:12、深夜23:47など、毎回異なる生活時刻のアンカーがあるか。
*   **気候多様性 (Weather/Season Diversity)**: 湿気、エアコンの風、冷えた廊下、雨の日の匂いなど、季節や天気の息遣いが分散しているか。
*   **空間多様性 (Room/Space Diversity)**: ベランダ、洗面所、スーパーのレジ前、玄関先など、多様な生活空間が描かれているか。
*   **感情多様性 (Emotional Diversity)**: 恥ずかしさ、安心感、ささやかな祝祭感など、感情のグラデーションが豊かか。

### 2.4. 誇大一般論の検知・排除 (`unsupported_generalization_count`)
「現代人は孤独である」「人間は誰しも弱い」といった、裏付けデータ（Source Trace）のない**『巨大な抽象的一般論（TEDトーク風スロップ）』**をカウントし、ペナルティを課します。
すべての主張は以下の3つに分類され、`unsupported` が検出された場合は即 FAIL とします。

1.  **Source-Backed（生活裏付けあり）**: 実在の観測ソース（Reddit、知恵袋など）に基づいた具体的なあるある。
2.  **Inferred（論理的推論）**: 観測事実から「はうちゃん」が当事者として優しく推論した解釈。
3.  **Unsupported（根拠なき誇大主張）**: 統計や生活事実の裏付けなく、知的に見せるためだけに書かれた一般論。

## 🛠️ 3. 監査メトリクス・仕様 (Technical Specifications)

次世代バリデータが実装すべき、決定論的メトリクスの閾値は以下の通りとします。

| メトリクス名 | 期待値 (Threshold) | 判定エラーコード | 説明 |
| :--- | :--- | :--- | :--- |
| `example_contamination_ratio` | $< 0.05$ (5%未満) | `PROMPT_COLLUSION_DETECTED` | プロンプト内の例文の再利用率 |
| `humanity_entropy_score` | $\ge 0.75$ | `CADENCE_PATTERN_LOCK` | 時刻・気候・空間・物体の多様性分散値 |
| `unsupported_generalization_count` | $= 0$ | `ABSTRACT_TED_TALK_SLOP` | 根拠なき誇大一般論の出現回数 |
| `mundane_object_density` | $\ge 3$ 個 / 1000字 | `REALITY_GROUNDING_FAIL` | 生活温度を持つ物理オブジェクトの密度 |
