# ADR 0044: 秒算マネーの編集参照を分解観察へ限定する

## ステータス

Accepted

## 決定

秒算マネーでは、編集参照を内容の模倣元や事実ソースとして扱わない。12件の参照レジストリを `config/references/byosan_money_editorial_references.json` に分離し、構成、情報密度、図解、テロップ、サムネイル、画面転換の要素だけを観察する。

役割は次のように固定する。

| 参照 | 分解して見る役割 |
| --- | --- |
| PIVOT | 日本語字幕、話者配置、章転換、ビジネステンポ、サムネ構図 |
| Bloomberg Originals | 人物・現場・チャート・地図・資料・ナレーションの切り替え |
| Reuters Graphics | ニュースを一枚の図へ変換する方法 |
| Financial Times | 金融チャートの余白、色、注釈、比較 |
| The Pudding | データ→問い→発見→次の図という進行 |
| Visual Capitalist | 一画面比較、ランキング、産業構造の図解 |
| Our World in Data | 軸、単位、期間、注釈を備えた単純チャート |
| FRED | 一次系列からのマクロチャート生成 |
| MacroMicro | 景気循環、株価、金利、PMI、在庫の接続 |
| Koyfin | 企業比較、利益率、コンセンサス、評価、ETF、債券、マクロの整理 |
| TradingView | 価格・指数・為替・商品チャートの期間、イベント、強調 |
| Canva YouTube Thumbnails | 文字量、顔の大きさ、余白、視線誘導 |

毎run、`runId` と選定角度から3〜5件を決定的に選び、少なくとも3つの役割グループを含める。選定された要素は `editorial_reference_plan` として成果物、台本メタデータ、制作監査へ記録し、シーンの図解・章転換・字幕強調へ実際に割り当てる。

## 禁止事項

- 参照先のサイト名、ロゴ、固有文言、素材、テンプレート、結論を再現しない。
- 編集参照を `claims.sourceIds`、一次資料、ニュース探索、数値の根拠へ入れない。
- 毎回同じ3〜5件を固定しない。
- 「PIVOT風」「Bloomberg風」のような単一サイト模倣の指示を生成しない。

## 受け入れ条件

- レジストリが12件で、事実ソースのID名前空間と衝突しない。
- 選定計画が3〜5件、3役割グループ以上、重複なしである。
- 異なるrunの選定組み合わせが変わり得る。
- 選定計画の全参照がシーンのレンダー戦略へ割り当てられる。
- 事実claimに編集参照IDが混入した場合は、仕様監査と制作監査が失敗する。
