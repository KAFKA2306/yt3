# ADR 0037: Visual Reference Mirroring & CTR-First Thumbnail Prompting

## ステータス
Accepted

## コンテキスト
Humanity Observatory のサムネイル制作では、話者レジストリを固定の言い回しに縛りすぎると、実際の見た目・空気感・クリック率最適化の判断が鈍る。

特に雨晴はう、もち子さんのような既存キャラクターは、抽象的な性格タグだけではなく、立ち絵・設定画・配色・シルエットを見たほうが、生成方針を安定して再現できる。

また、YouTube サムネイルでは「文字の即読性」「主役の明瞭さ」「スマホ表示での強さ」が最優先であり、話者設定よりも視覚的 CTR を支える設計が必要である。

## 意思決定
以下を標準運用とする。

### 1. 公式参照画像をローカルにミラーする
- 公式サイト上で確認できる参照画像は、`assets/reference/` に保存してローカル参照にする。
- 本件の基準画像は次の 4 点とする。
  - `assets/reference/amehare_hau_stand.webp`
  - `assets/reference/amehare_hau_design.webp`
  - `assets/reference/mochikosan.webp`
  - `assets/reference/mochikosan_design.png`
- 生成時はこのローカル素材を優先し、都度リモート参照に依存しない。

### 2. Speaker Registry は「見た目優先」で記述する
- 話者の定義は、固定のキャッチフレーズよりも visual tags を優先する。
- 雨晴はうは「小柄」「水色系の安心感」「清潔感」「堅すぎない」「日常寄り」を基準に扱う。
- もち子さんは「かなり小柄」「童顔寄り」「模型店 / プラモ系の空気」「頑張る小動物感」「生活感のある親しみ」を基準に扱う。
- `normal / あまあまスタイル` のような古い表現は、必要に応じて置き換えてよい。

### 3. サムネイルは CTR 優先で組む
- 文字は大きく、太く、スマホで即読できることを優先する。
- 主役のキャラクターは右側に大きく置き、テキストは左側に強く寄せる。
- 背景は白ベースで、余白を多く取り、低彩度で読みやすくする。
- かわいさは維持するが、装飾より視認性を優先する。

### 4. プロンプトは固定文よりも目的別に再構成する
- 画像生成では、古い表現をそのまま再利用するのではなく、参照画像と目的に合わせて書き換える。
- 具体的には、次の順で組み立てる。
  1. 参照画像
  2. キャラの視覚タグ
  3. クリックさせたい構図
  4. 文字の可読性
  5. 禁止事項

### 5. 生成物の保存先を分ける
- 生成画像は `runs/humanity_observatory/<date>-<theme>/` に版管理して保存する。
- CTR 優先版、比較版、再生成版は、上書きせず別名で残す。

## 運用規約
- 公式参照画像は、必要に応じて追加取得してよいが、まずはローカルミラーを優先する。
- 参照画像の取得元が明確でない場合は、採用しない。
- 話者名の語感よりも、実際の見た目と画面上の役割を優先する。
- サムネイル案は、文字の強さと構図の明瞭さを最優先で評価する。

## 影響
- 参照資産がローカル化され、生成方針が毎回ぶれにくくなる。
- 話者レジストリが、実運用に合う視覚的な定義へ更新される。
- サムネイル制作で、CTR と可読性を優先した判断がしやすくなる。
- 固定表現への依存が減り、より自然なプロンプト再構成ができるようになる。
