# ADR 0030: 人類観測所（Humanity Observatory）システム v1

## 状態
決定済み（Accepted）

## 文脈
「思考断面」という仮称から始まった第3チャンネルの構想を、自律稼働型の知的祝祭インフラとしてyt3リポジトリに統合した。既存の金融・ASMRとは異なる独自のブランド倫理と監査基準を定義する。

## 決定事項
以下の5つの柱を「人類観測所 v1」の決定仕様とする。

### 1. 中心重力：Lovable Clumsiness
- **「人類、みんな不器用すぎて愛おしい。」** を唯一の重力源とする。
- 知性を「人類を雑に扱わないこと」と定義し、専門用語によるマウントを構造的に禁止する。

### 2. ブランド温度：夏の夕方
- 基調を「夏の夕方の空気感」「放課後の安堵感」に固定する。
- 配色：Base White (#FFFDF8), Soft Sky (#BFE7FF), Evening Orange (#FFB86B)。
- モチーフ：生活感を伴う抽象要素をその都度選定する。
- 仕様に焼き付けず、制作時の文脈に応じて差し替える。
- ここでの制約は system prompt のみに適用し、成果物側の例示までは縛らない。

### 3. 監査システム：Humanity Audit v1
- 従来の「品質監査」を超えた「態度監査」を実装。
- **黄金律**: 「この動画を見た人が、ちょっとだけ自分を責めるのをやめられるか？」を最終ゲートとする。
- `AuditAgent` による 8レイヤー監査（Humanity, Reality, Tone, Anti-Doomcool, Afterglow, Structure, Drift, Preservation）。

### 4. 構成の規律：祝祭のシーケンス
- 生活導入 → なぜ？ → 構造分析 → 人類理解 → 微笑み → 未解決の問い、の順序を強制。
- 完璧な答え（Closed Loop）を禁止し、視聴者の脳に余白を残す。

### 5. 実行インフラ：Standardized Runtime
- `src/humanity_observatory_workflow.ts` による専用ランタイム。
- `data/humanity_pulse.md` をシードとした自律生成。
- `task run:humanity` によるワンコマンド実行。

## 帰結
- 思想と実装が完全に同期され、レガシーな仮称（思考断面・認知ノイズ倶楽部）を排除した。
- 「インターネット賢者」への崩壊リスクが、決定論的監査とプロンプト規律によって最小化された。
