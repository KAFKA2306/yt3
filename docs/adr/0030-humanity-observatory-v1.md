# ADR 0030: 人類観測所（Humanity Observatory）システム v1

## 状態
決定済み（Accepted）

## 文脈
「思考断面」という仮称から始まった第3チャンネルの構想を、自律稼働型の知的祝祭インフラとしてyt3リポジトリに統合する必要があった。既存の金融チャンネル（秒算マネー）やASMR（夜話アーカイブ）とは異なる、独自のブランド倫理と監査基準が求められた。

## 決定事項
以下の5つの柱を「人類観測所 v1」の決定仕様とする。

### 1. 中心重力：Lovable Clumsiness
- 「人類、みんな不器用すぎて愛おしい。」を唯一の重力源とする。
- 知性を「人類を雑に扱わないこと」と定義し、専門用語によるマウント（IQマウント）を構造的に禁止する。

### 2. ブランド温度：夏の夕方
- 視覚・演出の基調を「夏の夕方の帰り道」「放課後の安堵感」に固定する。
- 配色：Base White (#FFFDF8), Soft Sky (#BFE7FF), Evening Orange (#FFB86B)
- モチーフ：コンビニ、河川敷、アイス、洗濯物等の生活感を必須とする。

### 3. 監査システム：Humanity Humanity Audit v1
- 従来の「品質監査」を超えた「態度監査」を実装。
- **黄金律 (Golden Rule)**: 「この動画を見た人が、ちょっとだけ自分を責めるのをやめられるか？」を最終ゲートとする。
- 8レイヤー監査（Humanity, Reality, Tone, Doomcool, Afterglow, Structure, Drift, Preservation）。

### 4. 構成の規律：祝祭のシーケンス
- 生活導入 → なぜ？ → 構造分析（仕様解説） → 人類理解（翻訳） → 微笑み → 未解決の問い、の順序を強制。
- 完璧な答え（Closed Loop）を禁止し、視聴者の脳に余白を残す。

### 5. 実行インフラ：Source-Bound Runtime
- `src/humanity_observatory_workflow.ts` による専用ランタイムの構築。
- `data/humanity_pulse.md` をシードとした自律生成。
- `task run:cognitive` によるワンコマンド実行。

## 帰結
- 思想（憲法）と実装（Audit/Config）が完全に同期された。
- 「インターネット賢者」への崩壊リスクが、決定論的監査とプロンプト規律によって最小化された。
- 人間味のある生活感と、高度な構造分析が共存する独自の知的エンタメ枠が確立された。
