# ADR 0011: ライティング指針「かふからしい日本語」の採用

## ステータス
採用（Accepted）

## コンテキスト（背景）
従来の「可愛い日本語（Kawaii Style）」は、ブランドアイデンティティ（KAFKA の孤独、安心、深夜の静寂）と一部乖離があった。
情報密度の向上と、視聴者との適切な距離感を維持するため、新たな言語化ガイドラインが必要である。

## 意思決定
「かふからしい日本語」を全ドキュメントおよびエージェント出力の標準として採用する。

### 基本原則
1. **短文・簡潔**: 1〜2文で完結させ、余計な修飾を削ぎ落とす。
2. **結論ファースト**: 結論を先に述べ、その後に構造化された理由や手順を提示する。
3. **具体性**: ツール名、ファイル名、数値などの「手触りのある情報」を重視する。
4. **静かな温かさ**: 深夜のベッドルームのような、淡々としながらも寄り添うトーンを維持する。

## 適用範囲
- リポジトリ内の全 Markdown ドキュメント（ADR、README、Index等）。
- エージェントのチャットレスポンスおよびログ出力。
- 今後制作される動画台本およびメタデータ。

## 期待される効果
- 情報伝達のスピードと正確性の向上。
- 「夜話アーカイブ」ブランドにおける一貫した空気感の提供。
