# ADR 0041: 第3ドメイン「思考の断面 (Cognitive Cross-section)」の定義 🌸

## 📝 プロベナンス表示 (Claim Provenance)
- **VERIFIED**: `GEMINI.md` におけるドメイン隔離原則および `ADR-0031`, `ADR-0033` の命名境界ルールを確認。
- **OBSERVED**: ユーザーとの対話により、第3の作品方向性を「メタ認知・認知バイアス・心理的デバッグ」に決定。
- **INFERRED**: 既存の「秒算マネー（マクロ経済）」および「人類観測所（日常・情緒）」との重複を避けるため、極めて抽象的かつ分析的な「臨床的（Clinical）」なトーンが必要である。

決定済み（Accepted） ✨

## コンテキスト（背景）
YT3 プロジェクトのポートフォリオを完成させるため、金融・日常に続く第3の柱として「知性そのものの構造」を扱うドメインが必要となった。既存ドメインが「外の世界（経済）」や「隣人の生活（人類）」を対象とするのに対し、本ドメインは「自分自身の思考プロセス（メタ認知）」を解剖の対象とする。

---

## 決定事項

### 1. ドメイン基本情報
- **ドメインID**: `cognitive_cross_section`
- **作品名**: 思考の断面 (Cognitive Cross-section)
- **バケット名**: `cognitive_cross`
- **主要トーン**: 臨床的、解剖学的、ミニマリズム、高密度知性
- **禁止色**: #103766 (秒算ネイビー), 人類観測所のパステルカラー全般

### 2. 視覚的アイデンティティ (Visual Identity)
- **ベースカラー**: 純白 (#FFFFFF) または 深墨 (#111111) のモノクローム
- **アクセントカラー**: 認知のバグや洞察を示す「シグナル・レッド (#FF3B30)」または「ニューロン・バイオレット (#8E44AD)」
- **フォント**: `Geist` (Sans/Mono) を全面的に使用し、グリッドに基づいた精密なレイアウトを強制する。
- **視覚言語**: 断面図、フローチャート、ワイヤーフレーム、抽象的な幾何学形態。

### 3. 音声・音響設計 (Acoustic Specification)
- **話者設定**: 感情を排した「分析的ナレーター」（玄野の別モデル、または極めてフラットな新プリセット）。
- **BGM**: グリッチ、ミニマル・アンビエント、心拍数に近いパルス音。

### 4. 監査基準 (Specific Audit Gates)
- **COG-001 (Jargon Density)**: 認知心理学・行動経済学の専門用語が適切に配置されているか。
- **COG-002 (Visual Clarity)**: 図解の密度が一定以上か（単なる立ち絵動画を禁止）。
- **COG-003 (Meta-Reflection)**: 視聴者自身の思考を誘導する「問いかけ」が含まれているか。

---

## 帰結

*   **メリット (Benefits)**:
    *   既存ドメインと完全に差別化された、知的・抽象的なファン層を獲得できる。
    *   「思考のバグ」という普遍的なテーマを扱うことで、高い保存価値（Evergreen Content）を創出できる。
*   **デメリット (Trade-offs)**:
    *   高度な図解が必要となるため、動画生成パイプラインの複雑性が増大する。
    *   トーンが冷たくなりすぎるリスクがあるため、アクセントカラーによる「知的興奮」の演出が重要となる。
