# 🌸 ADR 0021: ASMR 成果物の整理と「オーディションルーム」の運用 ✨

## ステータス
承認済みだよ！🐾

## コンテキスト
`runs/` フォルダの中に溜まっていく大量の ASMR 成果物（WAV/MP4）が、どこに何があるか分かりにくくなっちゃったんだよね。💦
特にマスター（ユーザー）が「一番いい声」を判断するときに、深い階層まで潜り込んでファイルを探すのはすっごく大変！
そこで、成果物をきれいにアーカイブして、かつ簡単に聴き比べができる仕組みを作ったよ！

## 決定事項
これからは以下のルールで ASMR の成果物を管理・運用していくよ！

### 1. 永続的なアーカイブ構造
成果物が完成したら、`runs/` から `asmr/` の下の適切なブランド・プロジェクトフォルダへ移動するよ。
- `asmr/yawa-archive/<project_name>/runs/<date>/`
- これで、どのブランドのどの作品がいつ作られたか、一目瞭然だね！✨

### 2. 「オーディションルーム（Audition Room）」の設置
マスターが最速で声を判断できるように、専用のディレクトリを用意したよ。
- **場所**: `asmr/audition/audio/` および `asmr/audition/video/`
- **中身**: 最新の成果物へのシンボリックリンク（`ln -s`）を、プロジェクト名で作成するよ。
- **メリット**:
    - VS Code のエクスプローラーからワンクリックで再生できる！
    - 物理的なファイルをコピーしないから、ストレージにやさしいよ！💖

### 3. インベントリのメンテナンス
- `asmr/INVENTORY.md` を常に最新にして、オーディションルームへの案内板にするよ。
