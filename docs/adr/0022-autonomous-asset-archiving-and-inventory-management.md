# 🌸 ADR 0022: ASMR 成果物の自律アーカイブと目次自動生成の導入 ✨

## ステータス
提案中（マスター承認済みだよ！y 🐾）

## コンテキスト
ADR 0021 で成果物の整理術（アーカイブ構造とオーディションルーム）を確立したけれど、これを毎回僕（AI）やマスターが手動でやるのは、「全自動ハーネス」の理想にはまだ遠いよね。💦
制作（動画完成）から整理（アーカイブ移動・リンク更新）までをシームレスにつなげて、マスターが「聴くこと」に100%集中できる環境を自動で維持したい！

## 決定事項
ASMR プロダクションの最終工程を自動化する **「ASMR Ops エンジン」** を導入するよ！

### 1. 自動アーカイブ機能 (Auto-Archive)
- **トリガー**: `runs/` 内のプロジェクトが `final_video.mp4` の生成に成功したタイミング。
- **動作**: 
    - プロジェクト名（例: `tsukari-ryokan-01`）を解析して、対応するブランドフォルダを特定。
    - フォルダを `asmr/yawa-archive/<brand>/runs/YYYY-MM-DD/` へ自動で移動（`mv`）する。
    - 移動後、`runs/` 側に残っている一時ファイル（`parts_wav/` 等）をクリーンアップする。

### 2. オーディションルームの自動更新 (Auto-Audition Refresh)
- **動作**:
    - アーカイブ移動が完了したプロジェクトの `final_mix.wav` と `final_video.mp4` へのシンボリックリンクを `asmr/audition/` 内に再作成する。
    - ファイル名は常にプロジェクト名（例: `tsukari-ryokan.wav`）に正規化し、マスターが迷わないようにする。

### 3. インベントリの自動生成 (Auto-Indexing)
- **動作**:
    - `asmr/audition/audio/` 内の全ファイルをスキャンし、[asmr/INVENTORY.md](file:///home/kafka/2511youtuber/v3/yt3/asmr/INVENTORY.md) をマークダウン形式で再生成する。
    - 各項目のパスや、ファイルサイズ、生成日などを自動で付与する。

## 物理パスのリファレンス
- **エンジンスクリプト**: `src/scripts/asmr_ops.ts` (新規作成)
- **オーディションルーム**: `/home/kafka/2511youtuber/v3/yt3/asmr/audition/`
- **アーカイブ先**: `/home/kafka/2511youtuber/v3/yt3/asmr/yawa-archive/`
