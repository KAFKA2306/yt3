# 優しい年上お姉さんが、風邪ひいたあなたを温泉旅館で朝まで甘やかし看病してくれるASMR

この文書は `docs/adr/0007-oneesan-onsen-care-script.md` に統合済みのため、履歴として archive に退避する。

## 目的

この文書は、`/home/kafka/2511youtuber/v3/yt3/runs/2026-05-10/publish_new_work/` で制作する Safe 寄りの超長編 ASMR において、`voice caption`、本文、Whisper 検証条件を 1 つの制作基準として固定する。

## Voice Identity

- 話者: 年上お姉さん
- 声質: やわらかい、落ち着いた、少し低め、包容感がある
- 距離感: 近いが圧迫しない
- 呼吸感: 耳元で安定して届く程度
- 感情軸: 看病、安心、甘やかし、眠気誘導
- 維持条件: 章が変わっても声の明るさ、速度、圧の強さを変えすぎない
- 禁止条件: 別人のような急な高低差、テンション変化、話者混入

## 固定 Voice Caption

`voice caption` は全文共通で固定する。

```text
年上お姉さん、やわらかい低めの声、近距離の囁き、呼吸は一定、速度はゆっくり、感情は包容と看病、語尾はやさしく伸ばす、章をまたいでも声質を変えない、疲れている相手を安心させる温度、耳元でも圧をかけすぎない、眠気を壊さない落ち着き
```

## 生成ルール

- 台本は長文で一貫した一人称と二人称を維持する。
- 章ごとの感情差は許容するが、声質は維持する。
- 擬音、沈黙、耳かき、撫で、添い寝を中心にする。
- 露骨な性行為描写は入れない。
- 途中で別のキャラクター設定を混ぜない。
- `seed` は固定する。

1. 発熱の発見と看病の開始

3. 布団の中での添い寝
4. 耳かきと頭なで
5. 肩と背中のマッサージ
6. 就寝誘導と朝までの見守り
