# 夜話 ASMR 台本の選定（2026-10-10）

## 目的

ASMR 台本トラッカー（収集日 2026-10-01〜10-05 分）から、夜話アーカイブの制作元として使う候補を選ぶ。選んだ候補は、そのまま読むのではなく、Haiku 5.5 がオリジナル台本として書き直す際の参照元とする。

## 選定基準

1. 総合判定が PASS である
2. 収益化 OK、改変 OK、AI 音声（TTS）利用 OK がすべて満たされる
3. クレジット表記の条件を、概要欄で満たせる
4. 性的表現や監禁・暴力の描写が中心ではない（YouTube 方針と夜話の方針に合わせる）
